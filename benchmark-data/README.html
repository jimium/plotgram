回归门禁说明（角色感知）

布局 / 边路由改动后，用这里的快照对比，避免正确性或质量静默退化。本文是原 README 的可读版，含流程与指标图解。门禁按 smoke / product / demo / stress / mech 五角色分轨：product 硬、stress 默认软、demo 可债、mech 不门禁。

本地查看：./benchmark-data/serve-viewer.py → 打开 /readme；数据趋势页在 /。
产品规定：docs/architecture/方案计划/collinear-and-arrow-merge-comparison.md §2 （Allowed / NeedsSeparation / Degraded；不以共线计数归零为成功标准）。
角色分层方案：docs/architecture/重构方案/showcase-基线分层重构-2026-07.md。

概述

本目录存放角色分集样例、采集脚本、对比门禁、dated/latest 基线 JSON，以及可视化服务。日常回归以 collinear-baseline-latest.json 为准（默认 product + stress 合并）。监测对齐产品文 §2：看严重度与可归类，不追求「共线条数清零」。

常用命令

1. 采快照

# 默认 product + stress 合并
./benchmark-data/snapshot-collinear.sh

# 只采 product 门禁
./benchmark-data/snapshot-collinear.sh \
  --set benchmark-data/product-regression-set.txt

# 加入 demo 观测集（--set 可累加，多 set 自动去重保持顺序）
./benchmark-data/snapshot-collinear.sh \
  --set benchmark-data/product-regression-set.txt \
  --set benchmark-data/stress-probe-set.txt \
  --set benchmark-data/demo-observe-set.txt

# 可选: --runs 5  性能轮数
# 可选: --date YYYY-MM-DD  指定归档日期

覆盖当天的 dated 文件，并同步 latest。每条 sample 自动注入 role 字段（取文件名第一段）。

2. 对比门禁

# 默认：product 硬 / stress 软 / demo 软 / mech 不门禁
./benchmark-data/compare-collinear.sh \
  benchmark-data/collinear-baseline-latest.json \
  path/to/new-snapshot.json

# 显式把 stress 质量也走硬 fail（探针严格模式）
./benchmark-data/compare-collinear.sh --strict-stress <base> <cur>

# 布局故意改了（node_fp 变）：
./benchmark-data/compare-collinear.sh --allow-node-fp <base> <cur>

# 正确性过、质量债已知且要放行（全角色质量轨转 WARN，仍 exit 0）：
./benchmark-data/compare-collinear.sh --allow-quality-debt <base> <cur>

抬基线：确认改进或债已记录后，再跑 snapshot，并在 JSON 的 note 里写清 raise 原因，强制带角色示例：

raise product: …原因…；残余: product.foo
raise stress (expected): …探针可接受…；残余: stress.layout-stress-nested

3. 可视化 + 本文

./benchmark-data/serve-viewer.py
# http://127.0.0.1:8765/       趋势对比
# http://127.0.0.1:8765/readme 本文

node_fp — 节点几何指纹

图 4 · node_fp 只看节点中心；路由改边通常不变
  • 是什么：每个节点中心 (cx, cy)（×100 四舍五入）按 node_id 排序后拼串，FNV-1a 64-bit → 16 位 hex。
  • 量什么：只反映节点位置/尺寸中心；不含边、label、分组框。
  • 不变：节点没动（或中心精度内没动）。只改边/sanitize 时应保持。
  • 变了：节点被重定位。默认质量轨 FAIL；故意布局变更用 --allow-node-fp。

源码：layout/metrics/collinear.rs → node_fingerprint。

ortho.* 与性能 / 确定性

ortho.* 来自路由 debug 计数。其中 degraded_count 对应产品语言 Degraded（空间不够时的可解释残余）：允许有残余，但相对基线计数不得无说明地上升。其余 ortho 字段仍偏诊断，不单独门禁。尚无 per-reason 分布（对齐 §2.3 的后续缺口）。

字段来源门禁
ortho.degraded_count正交 debug质量·不升
median_ms 等bench-phases质量·预算
det两次 SVG SHA-256硬

性能预算（质量轨）：基线 <10ms 允许绝对 +5ms；否则相对退化 ≤ 约 +10%。det=false → 正确性硬失败。

门禁判定（角色感知分轨）

每条样本在 JSON 中带 role 字段（取文件名第一段：product / stress / demo / mech / smoke）。compare-collinear.sh 按角色决定质量轨是否挡合并。缺 role 字段时按文件名推导（兼容旧 baseline）。

轨检查product / smokedemostressmech
正确性（硬） edge_crosses_group_interior 不升；det=true FAIL FAIL FAIL FAIL
质量（默认真） exact_sev / tight_sev；lint through/trunk/err；ortho.degraded_count；perf；node_fp FAIL WARN / 可债 WARN（--strict-stress 改硬） 不门禁
观测（WARN） allowed_share_len 可升；若 allowed↑ 且 exact 未降 → 提示抽检误标 Allowed 同现网 同现网 同现网 —

退出码：正确性轨 FAIL 或质量轨 product/smoke FAIL → exit 1；质量轨 stress/demo/mech 仅 WARN（--strict-stress 时 stress 也 exit 1）。每条消息带 (role=xxx) 标注。

常见读法：group_interior ↓ 但 sev ↑ → 正确性 PASS、质量 FAIL（债）；确认后 --allow-quality-debt，抬基线时在 note 写清残余。Degraded 变多同理须有 note / reason，不能 silently 堆 count。

约定

  • 只保留有意义的 dated 快照：中间实验步不要堆进本目录；至少留 latest + 上一版。
  • 不要改 latest 却不写 note：后续对比靠 note 理解 raise 原因。
  • 验证用本脚本构建的 release 二进制，勿盲目信任陈旧 ./target/release/plotgram。
