# hierarchical 样例

按结构能力分桶（见上级 [README](../README.md) 三层模型）：

| 目录 | 含义 |
|------|------|
| [`flat/`](flat/) | 无 group、无 PartitionGrid |
| [`group/`](group/) | 有 group；含用 group 表达分区的旧「泳道」样例 |
| [`partition/`](partition/) | 真 PartitionGrid 占位（可空，等 M5） |

角色前缀仍为 `smoke.` / `product.` / `demo.` / `stress.` / `mech.`。
