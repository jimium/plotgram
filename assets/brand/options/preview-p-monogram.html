Plotgram — Text → Diagram

12 个方向。产品定位：文本画图（用户写文本，自动生成图表/流程图）。logo 必须传达「文字 → 图形」的转化关系。

核心隐喻候选： ① 文本行 → 节点/箭头（最直接）② 光标 + 节点（编辑器感）③ 「/」斜杠作为分隔符（命令感）④ 代码括号 []（文本外壳）⑤ 文字变图形的视觉转译
方向 A · 文本 → 节点（直接转译）
A1
文字行 → 节点链
上方：横线（文本）+ 节点 = 文字被转译成图。下方：箭头 + 矩形 = 流程图。最直白的「文本→图」
A2
三行文本 → 树
左侧 3 行文字 → 右侧 3 节点树状结构。最贴近产品：「写列表就生成树图」
A3
代码语法 → 图
`A→B` 这类文本语法 → 渲染成节点连线。表达 Mermaid/Plotgram 类产品的核心
方向 B · 光标 + 图形（编辑器）
B1
编辑器 + 生成图
左侧文本编辑器（带光标）→ 右侧自动生成的图。Notion AI / Cursor 范式，最贴近产品 UI
B2
光标 + 节点（V5 演化）
V5 基础 + 文字行上下文。底部光标 = 文本编辑器隐喻
方向 C · 斜杠 / 命令符
C1
斜杠 / 命令
`/` 命令符 = 输入触发。Notion/Linear 命令面板感。斜杠发出节点/箭头
C2
方括号 [...]
`[ ... ]` 文本容器包裹节点。Mermaid/代码块语法。开发者/技术感
C3
引号包裹
「"…"」引号 = 文本，包裹节点图。自然语言提示词的视觉化
方向 D · P 字母 + 节点（融合 V5）
D1
P 弧 → 节点链
V5 演化：P 的弧线尽头变成节点，节点继续延伸出箭头 + 矩形。「P 不只是字母，是图」
D2
P + 终端提示符
`>` 提示符 + P + 节点。终端/REPL 感，开发者友好。命令行式 plotgram
D3
代码块里的 P
把 `A → [□] → [□] → ●` 这类 Plotgram 语法画在代码块里，底部光标。开发者最熟悉的形态
方向 E · 单字标（P+dot 极致版）
E1
P + 文本行节点
P 旁边是文本行 + 数据点列。P = Plot 缩写，文本+点是 plot 的本质
E2
P 内含 A → 节点
P 的弧内嵌一个字母 A。P = Plot，A = 节点起点。表达「文字 → 图」的最短路径
