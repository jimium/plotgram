Brand exploration · Plotgram

Logo direction board

产品名已定为 Plotgram（plot + gram）：文本/DSL → 结构化图表。 下面是 8 个风格家族 × 18 个具体方案。每个卡片含大图标、16px favicon、以及字标组合。 请先选方向编号（如 C2 / F1），再进入精修。

命名可读性：Plot（绘制/图）+ gram（书写单位 / diagram / program）。 应传达：结构化、可路由的图、从文本到图形的转化。 刻意避开：旧 Drawquill 紫青渐变、通用 AI 紫、过度拟物羽毛笔。
A

P 字标 · 图即字母

把 P 做成可识别的品牌核：字母本身就是一张小图。适合 app icon / favicon。

A1
P · 节点落点
实心圆角底 + 镂空 P，弧线终点落一枚青绿节点。像「字母完成了一次连线」。
A2
P · 流出箭头
线型 P，从碗口伸出箭头接到矩形节点。更「流程图」，暖橙强调动作。
A3
P · 双锚点
深绿圆章 + 亮绿锚点。偏「工具/基础设施」气质，适合 CLI / SDK。
B

文本 → 图 · 转化隐喻

最直白的产品叙事：左边是书写，右边是结构图。适合落地页与文档头图。

B1
编辑器 → 节点
文档块 + 光标，输出矩形与圆节点。产品 UI 感最强。
B2
语法 → 渲染
上方 DSL 文本，下方已渲染的边与节点。对开发者一眼可读。
B3
三行 → 三节点
列表文本变成纵向节点链。极简、暗色友好，适合 IDE 插件图标。
C

正交路由 · 布局 DNA

呼应 Plotgram 的正交边路由与结构化布局——logo 本身就是一张迷你架构图。

C1
正交三节点
经典「两上一下」正交折线。一眼是架构图，不是通用 AI 标。
C2
框内折线
圆角画布内完成一次正交路由。像「一张图被装进容器」。
C3
四宫格网格
2×2 节点网格，强调布局系统。偏「引擎/库」而非消费级 App。
D

Plot 标记 · 点线面

从「plot」字面出发：数据点、轨迹、坐标系。更抽象、更品牌化。

D1
折线轨迹
经典 plot 折线，终点高亮。偏数据可视化，需确认是否过「图表」而非「流程图」。
D2
坐标 + 柱
轻量坐标系。更「分析工具」；若产品主打流程图，可作次要方向。
D3
星形图元
四节点交叉连接，像一张极简 graph。抽象度高，记忆点强。
E

Gram · 书写与语法

强调「gram」：书写单位、语法、可组合的符号系统。偏语言/DSL 气质。

E1
方括号语法
`[ □ ● ]` 像代码块里的图。开发者友好，和 Mermaid 类产品同语境。
E2
引号包裹
自然语言提示词被「说成」一张图。偏 Studio / LLM 创作场景。
F

字标优先 · Wordmark

不依赖复杂图标，用字母本身做识别。适合文档、CLI、GitHub README。

F1
plot / gram 双色
拆词着色：plot 墨色，gram 青绿。结尾圆点像句号/节点。
F2
等宽终端
Mono + 光标。极客、CLI-first。favicon 用 `>_` + 节点。
F3
衬线编辑感
Instrument Serif + 底线。偏出版/写作工具，和「画图引擎」反差大，可作大胆选项。
G

印章 / 徽章 · 应用图标

为 app icon、社交媒体头像设计的满版徽章。强调小尺寸可读性。

G1
黑底路由章
满版黑底 + 白节点 + 青绿折线。小尺寸仍清晰，适合默认 app icon。
G2
P 单字母章
最简：深绿底 + P + 一枚亮点。记忆成本最低。
H

混合实验 · 大胆选项

更有个性的实验方向，可能不适合作为唯一主标，但能拉开品牌差异。

H1
P 未完成 → 继续画
P 的弧线故意断开，接上金色箭头。隐喻「语言还在生成图」。
H2
角尺 + 准星
像绘图仪/工程尺。强调精确布局，和「随便画」的 AI 图工具拉开距离。

怎么选

回复你喜欢的编号即可，例如 A1 + C2 或 G1 做 icon，F1 做字标。 也可以说偏好：更技术 / 更产品 / 更抽象 / 要避开图表感。 选定后我会输出精修 SVG（logo / logo-dark / logo-icon）并替换 assets/brand/。
