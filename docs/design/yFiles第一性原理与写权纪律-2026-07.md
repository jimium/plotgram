## 0. 一句话

plotgram 学 yFiles 的**理念与纪律**，不复刻全量布局栈。Hier / 正交主路径的尺子只有两条：**每个几何自由度有且只有一个写者**；**落笔相零新决策**。

---

## 1. Hierarchical 最小完备闭环

剥掉三十年实现细节后，优秀 hierarchic 引擎的不变结构是五步：

```
① 拓扑决策    rank / order / 反转边          （组合相）
② 端口决策    每条边两端 (node, side, 位置)   （必须是显式决策，不可借住在 Ink）
③ 度量决策    坐标、缝宽、track 位置          （度量相）
④ 落笔        决策 → 几何，零新决策           （Ink）
⑤ 标注        label 与几何联合求解或至少联合避让
```

Atlas 三相（组合 → 度量 → Ink）对应 ①–④；⑤ 至少要进 Demand / 缝宽，完整 integrated labeling 可渐进。

---

## 2. 两条硬纪律

| 纪律 | 含义 | 反面（禁止） |
|------|------|--------------|
| **单写者** | 每个几何自由度有且只有一个写者 | 多处 `geometry =` / 端口位置 / track 坐标双写 |
| **落笔零新决策** | Ink / sanitize / 事后修只**展开**上游；下游不得推翻上游 | 在 Ink「发明」侧内位置、肘点拓扑、走廊坐标、穿组 dogleg |

**判断句（改任何落笔缺陷前先念）**：  
若修法是「在 Ink 再加一个特判」，多半是上游某个决策缺位的显影——先问「这个自由度的写者应该是谁」，再动手。

常见归类：

- **落笔职责**（几何展开，可在 Ink）：正交肘点展开、bundle 接合的纯几何、规范→画布的末端 orientation。
- **上游决策借住在 Ink**（必须搬家）：端口侧内位置、lane/track 真源、路径拓扑洞。

---

## 3. 设计时默认问什么

动手前按序回答：

1. **这个量的写者是谁？** 是否已在 Plan / 度量相有名义主人？
2. **落笔是否在发明？** 若 Ink 需要猜中点、猜肘点、猜 Main 轴——缺的是决策，不是启发式。
3. **是否多写者？** 间隙表、track、ports、label 带是否只从一处 publish、他处只读？
4. **是否事后硬修？** 几何不回写 Plan 的 repair，会破坏自反证；穿组等正确性应靠构造 + verify，不靠 dogleg 救命。

---

## 4. 优先级纠偏（长期有效）

- **勿把「先上真 MCF / 加深全局优化」当第一反应**；有界返工、端点序、单一真源往往更先。
- **勿为消 stress 数字或 lint warning 在 Ink 打补丁**；禁止图名特判（见 `AGENTS.md` §6）。
- **删冗余优于叠阶段**：旧正交 OVG、对拍影子、占位模块一类「第二宇宙」应删，不要用兼容层续命。
- **组合相最终应是一个**：weak/strong 是收缩策略参数，不是三条永久平行宇宙；输出类型不一致时，组合相尚未真正存在。
