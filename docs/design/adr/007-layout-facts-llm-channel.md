# ADR-007: 布局事实描述层——引擎写、LLM 读的几何只读通道

> 状态：proposed  
> 日期：2026-07-31  
> 关联：ADR-001（引擎不收图种）、AGENTS.md §1（写权纪律）

## 背景

`.taut` 对 LLM 是语义自足的：节点、关系、条件、分组、意图可从文件本身完整还原（已验证）。但**布局是派生几何**，pgm 里不存在——LLM 对渲染结果是"盲"的：

- 无法判断一次改动是否让图变丑（交叉增加、标签拥挤、组框错位）
- 无法回答空间问题（"灾备组在主 DC 的哪边"）
- 无法参与布局质量迭代，只能靠人看图

直接的补法都不成立：

- **喂坐标**：LLM 从 `(x, y)` 序列重建空间格局的能力差，坐标 dump 不可读
- **喂图给 VLM**：视觉模型数交叉、判对齐至今不可靠，且每次判断都带"可能看错"的疑云

无障碍领域的成熟结论同样适用：盲人读不懂按比例缩制的触觉地图，读得懂的是**提炼过的定性空间关系**（"出门左转，第二个路口右手边"）。LLM 同理。

## 决策

新增一条**布局事实描述层**（layout facts）：引擎在布局求解后导出定性化、LLM 可读的布局事实文本。核心约束：

1. **方向性固定**：pgm 是意图的写入通道（人/LLM 写、引擎读）；布局事实是几何的**只读通道**（引擎写、LLM 读）。两者中间隔着确定性引擎，永不短路。
2. **LLM 只做读者与评论者，不做几何写者**。LLM 读事实后的反馈只允许上提到参数/profile 层（如"层间距太挤"→ 调 spacing），由引擎重新求解。禁止任何"LLM 直改坐标/肘点"的路径——这是 AGENTS.md 写权纪律（每个几何自由度只有一个写者）在 AI 协作场景的延伸。
3. **内容形态是谓词而非坐标**：分层归属（`n3 在第 2 层`）、相对方位（`group A 位于 group B 右侧`）、路由事实（`回边 n15→n7 右侧绕行、跨 3 层`）、美学度量（交叉数、弯折数、标签碰撞）、异常点优先的叙述结构（先结论、再异常、原始几何仅可选附录）。谓词词表借用现成地基：定性空间推理（RCC8 / Allen 区间代数）与图布局美学度量，不从零发明。
4. **v0 形态**：`tautcore-cli` 增加 `--explain` 类输出，先服务内部 benchmark 评审闭环；语言在使用中长出，不先立规范。

### 派生用途（按落地顺序）

- **内部**：benchmark 快照附布局叙述，agent 判断布局回归；路由 bug 报告从"看图"变为可 diff 文本；对话式调图的前置感知。
- **无障碍**：SVG 内嵌结构化叙述，开箱即用的 WCAG 合规图表（EAA 已生效，政府/教育/金融采购硬指标；Mermaid / draw.io 空白）。
- **AI 可读性定位**：图表携带"语义源 + 布局事实"，可被 RAG 检索、被外部 agent 经 MCP 查询，无需视觉模型。
- **图表 code review**：PR bot 对 `.taut` 改动输出语义 diff（新增节点、路径改绕向、交叉数变化）。
- **训练/评测语料**：`pgm → 渲染 PNG + 导出描述` 管线，图与描述出自同一语义源，一致性构造性保证（零幻觉 caption）。一份 pgm 可榨四种监督信号：(图→描述)、(图→pgm)（de-rendering，Pix2Struct/DePlot 路线）、(图→QA 对)（图算法程序化生成，答案绝对正确）、(图→布局事实)（直接监督 VLM 最弱的空间关系能力）。增广维度全在自己手里：语义不变、像素大变（主题/字体/方向/间距），教会模型内容与呈现分离。**优先做 eval 集而非训练集**——可信的图表理解 benchmark 稀缺，被引用即钉入论文与模型卡片，且几千条精品即可。

所有派生用途共享同一信任前提：**描述由确定性引擎从真实几何导出，可承诺零幻觉**——这是相对 VLM 生成描述的护城河。

## 含义

- 引擎需在布局求解后保留足够的结构化中间事实（层归属、绕向、交叉、组相对方位），供导出层消费；导出层是纯读者，不回写几何
- 布局事实输出必须确定性（同输入同输出），受与渲染同级的快照测试约束
- 模板化描述用于机器消费；面向人的自然语言变体可由 LLM 改写模板产生，改写不得引入模板之外的新事实
- 语料管线（PNG + 描述 + QA 批量导出）是独立工具层，不进引擎 crate

## 备选方案

- **让 VLM 看渲染图**：判断不可靠、每次推断带疑云、成本高。放弃：符号事实精确且免费。
- **导出原始坐标给 LLM**：LLM 读坐标重建格局能力差。放弃：转谓词化。
- **允许 LLM 直接微调几何**：违反单写者纪律，特判换了个入口。放弃：反馈一律上提参数层。
- **先设计描述语言规范再实现**：无使用反馈的规范易过度设计。放弃：`--explain` v0 先行，语言在 benchmark 闭环中演化。
