🔍 核心问题诊断

P0 不必要弯折

现象：本可直连的边出现 Z 字弯；出发后立即折弯

根因：候选路径空间有限 + BEND_PENALTY(16) 偏低 + Slot 锚点不对齐

方案：提高弯折惩罚 → 扩展直连候选 → straighten 扩展到非正对端口

P0 边贴组边框走行

现象：边路径紧贴 group 边框线，视觉像"描边"

根因：走廊=组间隙中点（窄缝时贴边）+ 组近距惩罚偏弱 + 排斥是后处理

方案：走廊最小宽度保障 → 组近距惩罚×2 → 路由时硬排斥

P1 自环渲染质量差

现象：固定右上角矩形环，不感知周围空间，可能与邻居重叠

根因：独立模块，不经过 scoring/避障/lane，纯公式化几何

方案：空间感知方向选择 → 自适应尺寸 → 纳入 SegmentGrid

P1 布局对称性不足

现象：Fan-out 分支不对称；同层节点间距不均

根因：Brandes-Köpf 中位数不保证对称 + 无显式对称约束

方案：Fan-out 对称修正阶段 → 重心对齐 → 等间距分布

P2 回环边路由质量

现象：回环边绕行过长；多回环挤同侧；与正向边交叉

根因：延后路由但通道已被占；侧通道宽度固定

方案：路由前预留专用通道 → lane 分配 → 外环坐标

P2 路径搜索非最优

现象：复杂障碍场景下路径质量上限受限

根因：候选枚举 vs A*/VG 的根本算法差距

方案：引入正交 Visibility Graph → 渐进替代候选枚举

🗺️ 优化路线图

Phase A · 短期美学修复（1-2 周）

A1 自环重写 · A2 组边框留白 · A3 弯折消除 · A4 回环通道预留

风险：低 参数调整 + 局部逻辑改动，不动架构

Phase B · 路径搜索内核升级（2-4 周）

B1 正交 Visibility Graph · B2 端口约束求解 · B3 全局通道分配

风险：中 新模块引入，需创新模式（AGENTS.md §7）

Phase C · 全局优化 + 对称性（4-8 周）

C1 Fan-out 对称约束 · C2 边交叉最小化 · C3 自适应组间距

风险：高 架构级改动，需要帕累托评判
