## 1. Phase 5 要做什么（doc 23 主切片）

1. rank 轴进 `CoordinateProblem`（纵轴变量或第二次求解）
2. 删 `enforce_vertical_rank_gaps` → `MinSeparation`
3. **删 PRS** 预览路由 + `post_route/shell_expand`；RouteDemand **前馈**
4. 删 `spacing_demand_probe` 二次求解
5. `demand/` 收敛；删 `enforce_*` / guard 空壳
6. 删 `refine/` push 路径残留
7. 清 `runner.rs` 中 `algo == "architecture"` 等硬分支

**退出（doc 23）**：product 优于 Phase 0；路由前无预览路由；`algo==` =0；坐标求解次数 =1。
