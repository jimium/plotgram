## 0. 结论速览

- 当前 edge geometry（points/controls）有 **20+ 处写入点**，横跨 router 内部 C 段与 pipeline D 段，符合方案 §1.5「写权分散」判断。
- edge.labels 有 **两类写者**：router 建路时的 `build_*_labels`（初版）与 pipeline 末尾的 `label_avoidance`（终版）。
- route_annotation 有 **4 处 freeze/refresh**，每次几何变化后手工刷新，符合 §1.5「annotation 需手工 refresh」判断。
- route 阶段后节点仍会被移动（refine 推点、budget guard、architecture 质心重申、group frame 恢复），符合 §16.4 需删除的「refine 可推节点」语义。
- 目标终态（§4/§12）：GeometryMaterializer 是 points/controls **唯一写者**；annotation 与几何同源；label 在 geometry freeze 后独立求解；node freeze 后禁止推点。
