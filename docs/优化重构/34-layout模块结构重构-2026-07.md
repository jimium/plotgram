# layout 模块结构重构（2026-07）

> 对照：Group 一等公民退出（[33](33-Group一等公民-退出验证-2026-07.md)）后，算法主路径已稳定；本轮只做**目录/可见性**收敛，不改布局与路由算法。

## 目标分层

```text
pipeline  →  recipes(compile)  →  kernel(solve + Group IR)
                ↓                      ↓
              demand              group(corridor / write_counter)
                ↓
            routing(post_route / group_ctx)  →  quality(lint / refine / metrics)
                ↓
              snap
```

## 迁移摘要

| 旧 | 新 |
|---|---|
| `engines/common/group_bounds` | `kernel/group/bounds` |
| `engines/layered/*` | `kernel/layered/*` |
| `engines/common/{acyclic,...}` | `kernel/common/*` |
| `group/frame/spec` (+padding) | `recipes/frame_spec` |
| `group/frame` 几何 pass | **删除** |
| `post_route/*` | `routing/post_route/*` |
| `group/{context,border_shell,config}` | `routing/group_ctx/*` |
| `group/hierarchy` | `kernel/group/hierarchy` |
| `refine/*` | `quality/refine/*`（删 `push`） |

## 删除清单

- `group/frame/{bounds,sibling,realign,pass}` 几何生产链；`apply_group_frame`
- `group/shell_mut`（runner 直调 feedforward）
- `post_route_shell_expand` 死函数
- `refine/push.rs`
- 根目录 `engines/` / `post_route/` / `refine/`（经 stub 过渡后清空）

## 不搬

`types` / `traits` / `perf` / `geometry*` / `algorithm_config` / `catalog` / 顶层 `pub use` 公共面。
