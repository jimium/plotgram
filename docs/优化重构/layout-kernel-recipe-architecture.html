什么应该共享，什么必须独立

共享事实 稳定索引、尺寸、声明序、group tree、scope、用户约束。
共享数学 FAS、rank/order、BK、PAVA、Coordinate IR、组合和硬约束审计。
流程图独立 split–join、控制流主轴、feedback hub、end、pendant、装饰性 group。
架构图独立 scope tree、macro block、hub/client、基础设施行、group sizing、corridor。
共享生命周期 需求有界反馈、审计、冻结、路由调度和 edge finalize。
