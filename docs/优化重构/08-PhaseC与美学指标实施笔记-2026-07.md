## Phase C：生产就绪三件套

### C1. Fan-out/Fan-in 对称约束

**状态**：✅ 已完成

**目标**：同源分支节点关于父节点中心对称。

**实现**：`coordinate.rs` 中 `enforce_fan_symmetry()`，在 Brandes-Köpf + compaction 之后执行。

**安全约束**：
- 仅对「独占子节点」（parent_count == 1）操作
- 仅对「汇聚型后继」（所有子节点的后继集合相同）或叶级 fan-out 操作
- 碰撞检测：平移后不与同层邻居重叠

**效果**：
- `symmetric-fanout`: sym_dev 1.000 → 0.000（完美对称）
- 美学轨 PASS（无退化）
- 质量轨 PASS（exact_sev / tight_sev 无变化）
- node_fp 变化：2 个样例（预期内，节点位置调整）

### C2. 边交叉最小化（路由阶段）

**状态**：✅ 已统一检测算法并重新启用

**目标**：路由后主动减少边交叉。

**实现**：`crossing_reduction.rs`，检测交叉边对 → 尝试平移段 → 全局验证总交叉数下降。

**本次修复（2026-07-21）**：
- 统一 `segments_cross()` 与美学模块 `segments_intersect()` 一致（加入共线端点检测 + `on_segment()` 辅助函数）
- 添加 `shifted_segment_clearance()` 安全约束：平移后与平行边段保持 ≥10px 间距，与非平行段 ≥8px
- 偏移量改为小偏移优先：`&[4.0, -4.0, 8.0, -8.0]`
- 在 `run.rs` 中重新启用调用

**实际效果**：门禁全通过，但 clearance 约束阻止了所有平移尝试（密集图中安全空间不足）。当前 benchmark 集上无实际交叉消解，但代码已就绪，待稀疏图场景生效。

## Phase D：性能与默认开启优化（2026-07-21）

### D1. Port Solver 默认开启

**状态**：✅ 已完成

**目标**：将 Port Solver 从 opt-in 改为默认开启。

**实现**：
- `port_solver.rs`：门控改为默认开启（`PLOTGRAM_PORT_SOLVER=0` 关闭）
- 添加 `MIN_IMPROVEMENT = 2.0` 阈值：只有成本下降超过此值才接受端口变更，防止微小改善导致路由退化

**修复的回归**：password-reset degraded 1→4（Port Solver 选择了路由困难的端口）→ 通过 MIN_IMPROVEMENT 阈值解决。

**实际效果**：门禁全通过。当前 benchmark 集上 Port Solver 无实际变更（几何初始分配已足够好），但代码已就绪，待复杂图场景生效。

### D2. 后处理层裁剪

**状态**：✅ 已完成

**目标**：OVG 默认开启后，裁剪冗余后处理提升性能。

**实现**：`conflict_reroute.rs` 中 OVG 开启时 reroute 轮次从 2 减为 1。

**效果**：ecommerce x1_reroute 7.67ms → 6.24ms（-18%），门禁全通过。

### D3. OVG 大图性能

**状态**：⏭️ 跳过

**原因**：ecommerce +4%（34ms vs 33ms）是 OVG 路径搜索的固有开销，换取 degraded -67% 的质量收益。进一步优化空间过滤的收益/风险不合适。

### D4. stress-deep 性能优化

**状态**：✅ 已完成（68 倍加速）

**目标**：stress-deep 75ms 是最大瓶颈图。

**根因分析**：
- 通过临时 perf 计时定位：87ms 全部耗在 `ObstacleIndex::build()`
- 该函数对 63 节点的 252 个角点做 O(n²) 可见性预计算（31,626 对角点）
- 但 mindmap 树布局中所有边都是父子直连（depth diff=1），根本不需要障碍避让

**实现**：`edge_routing_organic.rs` 中，当 `is_mindmap && node_depths.is_some()` 时跳过 ObstacleIndex 构建，将 `obstacle_index` 改为 `Option<ObstacleIndex>`。

**效果**：
- stress-deep: **75ms → 1.1ms（68 倍加速）**
- 门禁全通过（正确性 + 质量 + 美学）
- 确定性验证通过
