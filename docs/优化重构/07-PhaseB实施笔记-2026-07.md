## B1. 正交 Visibility Graph (OVG)

### 实现文件

`crates/plotgram-core/src/layout/edge/edge_routing_orthogonal/visibility_graph.rs`

### 核心算法

1. **构建阶段**：
   - 收集障碍物膨胀后的 bbox 四角作为候选顶点
   - 对每对顶点，检查水平/垂直可见性（线段不穿任何障碍物）
   - 可见则添加边，权重 = 线段长度

2. **路径搜索**：
   - Dijkstra 最短路径
   - 边权 = 线段长度 + bend_penalty × 转弯次数
   - 端点通过投影连接到图

### 集成点

`path.rs` 的 `select_best_path_with_scorer_stats`：
- 在 Level 3（阶梯候选）之后添加 Level 4: OVG 路径
- 仅当无 strict 候选且 OVG 可用时启用

### 环境变量

- `PLOTGRAM_OVG_ENABLED=1`：启用 OVG（默认关闭）

### 测试

- `test_ovg_empty_obstacles`：空障碍物
- `test_ovg_single_obstacle`：单障碍物构建
- `test_ovg_simple_path`：简单路径搜索
- `test_ovg_path_around_obstacle`：绕行路径
- `test_simplify_orthogonal_path`：路径简化

## B2. 端口约束求解器

### 实现文件

`crates/plotgram-core/src/layout/edge/edge_routing_orthogonal/port_solver.rs`

### 核心算法

1. **初始化**：使用几何规则（`choose_pair_sides_with_group`）
2. **局部搜索优化**（小规模 < 50 边）：
   - 尝试所有端口组合
   - 目标函数：弯折预估 + 端口冲突惩罚
   - 迭代直到无改善

### 约束

- 同节点同侧边数 ≤ 容量（PORT_CAPACITY_PER_SIDE = 4）
- 正对端口优先（减少弯折）
- 回环边使用 feedback 分配

### 环境变量

- `PLOTGRAM_PORT_SOLVER=1`：启用端口求解器（默认关闭）

### 测试

- `test_estimate_bends_opposite`：正对端口弯折预估
- `test_estimate_bends_l_shaped`：L 形端口对
- `test_estimate_bends_same_direction`：同向端口
- `test_port_solver_disabled_by_default`：默认关闭

## B3. 全局通道规划器

### 实现文件

`crates/plotgram-core/src/layout/edge/edge_routing_orthogonal/channel_planner.rs`

### 核心算法

1. **收集通道候选**：
   - 组间隙中点
   - 节点间隙中点

2. **贪心分配**：
   - 按边序遍历
   - 为每条边分配负载最低的通道

### 数据结构

```rust
pub struct ChannelPlan {
    pub vertical_channels: BTreeMap<i64, Vec<usize>>,   // x 坐标 → 边列表
    pub horizontal_channels: BTreeMap<i64, Vec<usize>>, // y 坐标 → 边列表
}
```

### 环境变量

- `PLOTGRAM_CHANNEL_PLANNER=1`：启用通道规划器（默认关闭）

### 测试

- `test_channel_plan_empty`：空规划
- `test_channel_planner_disabled_by_default`：默认关闭
- `test_collect_channel_candidates`：候选收集
