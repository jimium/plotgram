## 0. 原则与红线

1. **正确性轨优先于重构轨**：同一 PR 不混「修穿模/对齐」与「拆巨型函数」。  
2. **先分析交付物，再改代码**：每项至少有数值化基线（坐标 / gap / 严重度）。  
3. **禁止**：图名特判；新建空壳 `EdgeGeometryContract`；无 degraded 硬丢边；几何未冻结时在 router 内开 `merge_overshoot`。  
4. **DoD 三件套**：节点坐标 diff 可解释 + 全量重叠严重度不升 + 相关单测绿。

### 建议总序

```text
O0  钉基线（既有失败 + 代表图坐标/严重度快照）
 → O1  V2 共竖干残余（视觉正确性）
 → O2  V3b-A architecture 复用（布局契约扩展）
 → O3  L5/L6 按需（仅当有可复现坏图）
 → O4  Phase D 确定性 / P2 边界（与 O1–O2 错开文件）
 → O5  R12 产品边界文档化（默认不改代码）
 → O6  重构轨（死代码 / SpaceBudget / phase 拆分）
```

O1 与 O6 **禁止同 PR**；O4 可与 O6 并行但文件集合不重叠。
