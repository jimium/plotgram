## 关键否定结论（避免重复劳动）

经实读核查，以下曾被怀疑的"重复"**不成立或需收窄表述**：

- `sugiyama_v2/coordinate.rs` 与 `architecture_v2/layout/coordinate.rs` **没有字节级函数重复**：sugiyama_v2 走 `NodeIndex` + Brandes-Köpf 体系；architecture 有独立的 string 图版 `uniform_initial_positions`/`resolve_x_overlaps`（平行实现，非拷贝），并通过 `assign_layer_centers_for_string_graph` 桥接复用 BK 核心。仅 `median_f64` 一处小工具重复（R-15）
- `layout/postprocess.rs` 的 bbox 计算与各算法的 `bounds_from_layout` / `compute_total_size` **职责不同**（前者含边路径采样与标签包围框，后者只算节点+组），R-3 只针对后者
