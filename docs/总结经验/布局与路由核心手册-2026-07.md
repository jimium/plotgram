## 0. 一句话

改布局/路由时：**先弄清「最终输出是谁写的」再调启发；几何未冻结前不做激进折点清理；用 `cargo run -p plotgram-cli` 验真；用节点坐标 + 重叠严重度谈退化；禁止图名特判。**

法则分两档：

| 标记 | 含义 |
|------|------|
| ★ | **硬红线**：违反会系统性假修好 / 不可复现 / 特判污染 |
| ○ | **强建议**：当前最佳实践；可用更好方案替换，但须说明写权与回归证据 |

## 1. 工作法则与失败模式

### 1.1 法则

| # | 档 | 法则 |
|---|----|------|
| 1 | ★ | **先追写权与时序**：改字段前回答「谁最后写入」。大阶段通常是 `route → snap/repulse → sanitize → label`；sanitize 会重建 label 时，避让必须在几何冻结之后。具体子阶段名见 §3.1（现状地图，可演进）。 |
| 2 | ★ | **激进清理勿过早**：router 内 sanitize 宜保守；会改变折点拓扑的逻辑（如 `merge_overshoot`）不得在节点仍可能重定位时启用（会反馈 space-budget → 假回归）。 |
| 3 | ★ | **勿信陈旧 binary**：优先 `cargo run -p plotgram-cli`；日志与源码不一致时先查 mtime / fingerprint（含沙箱注入的 `CARGO_TARGET_DIR`）。 |
| 4 | ★ | **退化要可量化**：节点坐标 diff + showcase **严重度**（非单图观感、非只数 violation）。仓库既有失败先钉死，勿与本次改动混谈。 |
| 5 | ★ | **禁止图名特判**；可接受合法单调台阶暂留；**不可为消 lint/warning 引入穿模**。 |
| 6 | ★ | **确定性迭代**：禁止靠 HashMap key 序驱动布局/路由（`AGENTS.md` §2）。 |
| 7 | ★ | **渲染不得反推路由语义**：FanIn/共享 trunk/sharp corner 应消费 annotation（或同等单一语义源）；禁止按 `points.len()` / 固定 index 猜。 |
| 8 | ○ | **refine 候选破约即拒绝本轮**：若候选**新制造**节点碰撞、层缝破坏等，回滚该候选并走既有降级；不是禁止一切推点，而是禁止「破约后再在反馈环里硬补」。 |
| 9 | ○ | **基线可抬、债须显式**：全量门禁数字不是永恒真理。有意抬基线时须说明原因与残余样例；不得把「单图好看」说成「无退化」。 |

### 1.2 常见失败模式

| 模式 | 识别 | 防御 |
|------|------|------|
| 陈旧产物 | 加了日志却看不到 | 先核 binary，再疑控制流 |
| 过早局部猜因 | 调偏移/分数，结果仍被后步覆盖 | 先找最终写者 |
| 节点动了当修好 | 视觉好但坐标整体漂 | 激进逻辑挪到几何冻结后 |
| 未读调用上下文 | 犹豫改签名，其实已有 map | 先读参数与阶段 |
| 阈值治死锁 | `cand==curr` 时调阈值无效 | 改打分，禁恒等胜出 |
| 多写者无最终所有者 | 改了 X 结果没变 | 明确字段最终写者 |
| 假设独占共享资源 | 赋锚未查占用 | 查 map → 切线错开 |
| 孤立决策 | 只看本边 | 视觉歧义按群体问题处理 |
| 路径点数猜语义 | 4/5 点样例好看，6 点误判 | annotation / `MergeInterval` 标记合流边界 |
| 全图投影当“同列” | 修一对却拉散跨组/宏 rank | 作用域至少 `(leaf-group, rank)` |
| 反馈后再推点补缝 | 局部好、全量穿模升 | 候选前后比违规集；新违规则回滚 |
| 合流重造整条路径 | 共享干有了，源 stub/走廊被盖 | 保留绕障前缀，只改必要 suffix |

### 1.3 改动后 DoD

1. `cargo run -p plotgram-cli` 验目标图  
2. 节点坐标相对基线可解释（仅预期节点动，或已说明为何整体漂）  
3. 相关单测 + 全量严重度/门禁有结论（持平、可解释上升、或显式抬基线）  
4. 无图名分支  
5. 目标图视觉通过但全量门禁失败时，只能声明「目标修复」，不得声明「无退化」

## 2. 母题与判定规则

### 2.1 两类系统问题

1. **语义错位（假邻居）**：邻居/边集宽于或方向异于 FAS **effective** DAG + **邻层**约束。  
2. **契约破坏**：陈旧下标、尺寸双轨、几何已换标签未换、端点离框、**检测成功却不修复**。

### 2.2 通用判定（审计复用）

1. DAG 语义单一来源（effective 邻接）  
2. 邻域默认 rank±1；长边经 dummy，禁止远端 real 直接进 median  
3. 后处理不得宽于主算法（coordinate / stub_fix / straighten）  
4. 硬过滤与软惩罚一致；检测为真须改善或显式 degraded  
5. 确定性枚举（显式排序 / `IndexMap` / `BTreeMap`）  
6. 端点在边界；换几何后重建标签；容器变异后重算下标；单尺寸源  

### 2.3 有意启发式（勿当 bug）

长边 barycenter/dummy 加权、`stub_fix` 长度容忍、straighten 直连偏好、长跨度侧通道车道、degraded fallback、合法单调台阶暂留、overlap 迭代上限等。

## 3. 正交管线与 sanitize（现状地图）

> 本节描述**当前**主路径，便于追 gap / 共锚 / 写权。  
> **可以**合并、重排、改名阶段；改时同步更新本图，并证明写权仍清晰（★1–2）。

### 3.1 当前阶段序（对照用）

```text
4b replan_slots
 → 4c straighten_align
 → 4d reroute
 → 4e stub_fix              ← 当前在 lane 之前
 → 4f lane_assignment
      └─ enforce_reverse_pair_min_gap  ← C 预修（正反向窄域）
 → S3 semantic_trunk_merge             ← 业务 FanIn，写 MergeInterval
 → S4 monitor outer reroute
 → 4g sanitize               ← 保守；collapse + simplify
 → S4.x monitor escape repair
 → B.2 monitor local trunk             ← 须在 S4/S4.x 之后写，否则易被覆盖
 → [pipeline] snap_and_repulse
 → sanitize_ext(merge_overshoot=true)
 → enforce_reverse_pair_min_gap  ← D 一次审计
 → enforce_reverse_pair_dock_separation
 → label_resolve             ← 最终避让，勿再被 sanitize 丢掉
 → dedupe labels on declared merges
```

正反向 gap 写权（当前约定）：C 预修（4f 末）+ D 审计；避免 4g 后连环 enforce。若重设计写权，用回归证明，不必固守旧阶段名。

### 3.2 Sanitize 职责（E0）

| 步骤 | 意图 | 注意 |
|------|------|------|
| `fix_endpoint_reverse_stub` | 切背向折点 | 禁止 stub-only 截断 |
| `ensure_outward_stub` / `repair_post_stub_inward` | 外向 stub | 已修内向肘 |
| `force_orthogonal` / `collapse_micro_jogs` | 整形 | 共线合并分数选角；非救穿模 |
| `simplify_path`×2 | 合并近共线 | 可压 parallel gap |
| `merge_overshoot`（宜几何冻结后） | 消 Z 折 | 无障时可能拉直侧通道台阶（R12） |
| 安全网回退 | 保连通 | 可能保留脏几何 → 依赖 degraded |

### 3.3 走廊、stub 与合流（经验边界）

1. **节点 stub 与组边框腿不是同一种资源**：节点端要 port outward/clearance；走廊已在目标组外侧时，入组腿应直接接边框，避免再按 `entry_side` 外走一步后折返。  
2. **勿用 sanitize 掩盖构造器错误**：走廊 Z 折先修 exit/entry/final leg；`collapse_micro_jogs` 无完整障碍语义，不宜当救穿模。  
3. **合流只改必要范围**：普通 FanIn 保留源 stub 与绕障前缀，目标附近接共享 trunk；同 rank 同出侧 pendant 可为对称在源 stub 后合流。  
4. **监控合流后置（当前）**：S4 外环与业务干分流；监控局部 trunk 写在 S4/S4.x 后，且只合目标同侧。  
5. **共享干标签去重**：同一显式 `MergeInterval.group_key` 上文案相同只留确定性代表。

### 3.4 层缝与 refine 作用域

- 避免全图按 X 投影枚举“同列”并逐节点下推（易跨 group / 宏 rank 级联扩壳）。  
- 层缝检查宜限定 `(leaf-group scope, sugiyama rank)`；普通节点只处理真实投影碰撞。  
- refine：**本轮候选**若新制造违规 → 回滚该候选；最终 guard 可修初始残余，节点移动须刷新 group frame 并重路由相关边。

### 3.5 全局变换与正交降级

跨 leaf 正确性优先级（P1）：`不穿组 ≫ 不穿节点 ≫ 短/共线`。`validated_corridor_path` 可接受避组脏走廊；refine 不得为消 through 毁掉已避组几何（P3）。门禁读两轨：见 `compare-collinear.sh` / 契约计划 C4。

全局变换（平移/缩放画布）后须保持正交与端点契约；降级路径须可观测（degraded），禁止静默斜线。

- ★ `RouteAnnotationSet` 用绝对坐标时，`translate_all` 必须同步平移 annotation（start/end、stub、protected run、merge、occupancy）。只平移路径会让合流角画成圆角。  
- ★ **禁止**：把密采样曲线/样条写回正交 `Polyline` 再交给无障碍的 `force_orthogonal`（会栅格化成假台阶）。  
- ○ **当前做法**：architecture / 正交原边的 refine 降级优先障碍感知 dogleg / 外廊，并与 lint 对齐做穿节点/穿组过滤；找不到干净通道则保留原边或显式 degraded。  
- ○ 允许演进为其它**障碍感知的正交**生成器（例如正交可见性），只要不走「密采样 + 无障栅格化」。  
- ○ 同宿 FanIn 若源均在目标同一侧：宜先统一目标正对端口再 semantic merge；stub 修正勿把成员旋散。  
- ○ **P3**：fallback **仅**处理当前已穿组边；已避组、仅 through 的边默认不进 dogleg（防毁掉走廊外绕）。

## 5. V3b 悬挂对齐（摘要）

**意图**：邻层单入边 leaf / 同锚多 leaf，在路由前把主轴对齐到 hub，避免「假邻居」式歪斜。

**要点**：

- flowchart：`sugiyama_v2` 内 `align_pendants_under_anchors`（宜在 `normalize_layout_to_padding` 之后、route 之前）。  
- architecture 不自动等同 flowchart L2；跨作用域对齐若做，须有明确最终写者，避免与 PRS / space-budget 互盖。  
- 路由后不要再挪节点做 pendant「补救」。

细则（P-Pendant / R1–R4 / pack）以代码与单测为准；不必把本手册当 V3b 规格书全文。

## 7. 重构 ROI 原则（非清单）

1. 死代码直接删（AGENTS §1）  
2. 障碍检测 / 采样常量一处定义  
3. `reroute_and_repulse` 与 pipeline 传同一 snap 配置  
4. 巨型阶段函数可按 phase 拆，便于时序审计——**拆分不等于冻结阶段名**  
5. sugiyama 与 architecture coordinate **不是**字节拷贝，勿误合并  
6. annotation 一旦存在，渲染 / 校验 / 标签归属复用同一语义源  
7. 多写者字段宜收敛为「检测 + 一个最终重申」，其余阶段拒绝破约候选  

lint 与性能冲突时：优先算法效果与简洁性（`AGENTS.md` §4）。

## 8. 给 Agent 的最短清单

1. ★ 先找最终写者；动坐标优先在路由前。  
2. ★ 验证用 `cargo run -p plotgram-cli`，核 binary / `CARGO_TARGET_DIR`。  
3. ★ 无图名特判；不为消 lint 引入穿模。  
4. ★ 回归：坐标 diff + 严重度；既有失败先钉死。  
5. ★ sharp/round、FanIn 看 annotation，不看路径点数。  
6. ○ §3 是现状地图，可演进；改架构时更新对照并留回归证据。  
7. ○ refine 本轮破约就回滚候选，不是禁止一切推点。  
8. ○ 单图修好但全量门禁红：声明「目标修复」或显式抬基线 + 列残余样例。  
9. WASM 禁用裸 `std::time::Instant`（`AGENTS.md` §6）。
