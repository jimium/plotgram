# 12 · 论文与资料书目（带注解）

> 每条注明：**读它拿什么**。标 ★ 的是"自研布局引擎前必须读"的核心文献。
> 检索提示：绝大多数条目可在 DBLP（`dblp.org`）搜作者+年份找到；GD（Graph Drawing 会议）论文多在 Springer LNCS，
> 作者主页常有 PDF；Graphviz / OGDF / ELK / adaptagrams 的技术报告在各自项目站点。

## 0. 教科书与综述（先读这两本，能省下几十篇论文）

- ★ **Di Battista, Eades, Tamassia, Tollis — *Graph Drawing: Algorithms for the Visualization of Graphs*, Prentice Hall 1999.**
  领域标准教科书。分层、正交、平面性、树、力导向各占一章，理论完整。读它建立术语体系。
- ★ **Kaufmann, Wagner (eds.) — *Drawing Graphs: Methods and Models*, LNCS 2025, Springer 2001.**
  各章由该子领域作者亲写，比上书更贴近实现。分层章（Sugiyama 框架）与正交章尤佳。
- **Tamassia (ed.) — *Handbook of Graph Drawing and Visualization*, CRC 2013.**
  最新、最全的手册。第 13 章（Hierarchical Drawing Algorithms，Healy–Nikolov）、第 5 章（Planarity）、
  第 12 章（Force-Directed，Kobourov）、第 17 章（Labeling，Wolff）都值得单独读。**如果只买一本，买这本。**
- **Kobourov — *Force-Directed Drawing Algorithms*（Handbook 第 12 章，也有独立 arXiv 版）**：力导向家族最好的综述。
- **Nikolov, Healy — *Hierarchical Drawing Algorithms*（Handbook 第 13 章）**：Sugiyama 各相的算法对照表。
- **Bennett, Ryall, Spalteholz, Gooch 2007 — *The Aesthetics of Graph Visualization*.** 美学准则的综述与实证汇总。

## 1. 分层布局（Sugiyama 家族）★

- ★ **Sugiyama, Tagawa, Toda 1981 — *Methods for Visual Understanding of Hierarchical System Structures*, IEEE Trans. SMC 11(2).**
  框架原文：四相分解、barycenter、priority 坐标法。读它理解"为什么这样切相"。
- ★ **Gansner, Koutsofios, North, Vo 1993 — *A Technique for Drawing Directed Graphs*, IEEE TSE 19(3).**
  **本领域最有工程价值的单篇论文**（dot 的实现说明）。含：network simplex 分层的完整伪代码与 cut value 增量维护、
  mincross 的 median+transpose 配方与边权 1/2/8 设计、x 坐标的辅助图建模、多边形通道内的 Bézier 拟合。附录必读。
- ★ **Brandes, Köpf 2002 — *Fast and Simple Horizontal Coordinate Assignment*, GD 2001, LNCS 2265.**
  线性时间 x 坐标分配（4-run 对齐 + 紧致化 + 中位平均）。工业默认。
- ★ **Brandes, Walter, Zink 2020 — *Erratum: Fast and Simple Horizontal Coordinate Assignment*（arXiv）.**
  修正原文 compaction 伪代码的错误。**不读会写出节点重叠的实现**，多个开源库踩过。
- **Eades, Lin, Smyth 1993 — *A Fast and Effective Heuristic for the Feedback Arc Set Problem*, Inf. Process. Lett.**
  Greedy-FAS，去环的工业标准，带质量下界证明。
- **Eades, Wormald 1994 — *Edge Crossings in Drawings of Bipartite Graphs*, Algorithmica.**
  两层交叉最小化 NP 难 + median 启发式的 3-近似界。
- ★ **Barth, Jünger, Mutzel 2002 — *Simple and Efficient Bilayer Cross Counting*, GD 2002.**
  $O(E\log V)$ 交叉计数。sweep 里要反复计数，没这个会很慢。
- **Matuszewski, Schönfeld, Molitor 1999 — *Using Sifting for k-Layer Straightline Crossing Minimization*, GD 1999.**
  sifting：质量优于 transpose，对长链友好。
- **Coffman, Graham 1972 — *Optimal Scheduling for Two-Processor Systems*.** 限宽分层的来源（调度算法的移植）。
- **Nikolov, Tarassov, Branke 2005 — *In Search for Efficient Heuristics for Minimum-Width Graph Layering with Consideration of Dummy Nodes*.**
  层宽与 dummy 数的权衡；node promotion 技巧。
- **Sander 1996 — *A Fast Heuristic for Hierarchical Manhattan Layout*, GD 1995.** 分层 + 正交 + 分组的早期完整方案。
- ★ **Forster 2002 — *Applying Crossing Reduction Strategies to Layered Compound Graphs*, GD 2002.**
  复合图（分组）的交叉最小化，08 篇的理论来源。
- ★ **Schulze, Spönemann, von Hanxleden 2014 — *Drawing Layered Graphs with Port Constraints*, JVLC 25(2).**
  端口约束在分层管线中的完整处理（ELK 的依据）。**做端口必读。**
- **Sugiyama, Misue 1991 — *Visualization of Structural Information: Automatic Drawing of Compound Digraphs*, IEEE SMC.**
  复合图（compound digraph）模型原文。
- **Bachmaier, Brandenburg, Brunner, Hübner 2010/2011 — *Global k-Level Crossing Reduction*.** 块级（长边整体）sifting。
- **Chimani, Gutwenger, Mutzel, Wong 2010 — *Layer-Free Upward Crossing Minimization*.** 另一条思路：先最小化交叉再分层。

## 2. 正交布局与平面性

- ★ **Tamassia 1987 — *On Embedding a Graph in the Grid with the Minimum Number of Bends*, SIAM J. Comput. 16(3).**
  最小弯折的最小费用流模型。正交布局的理论基石。
- **Batini, Nardelli, Tamassia 1986 — *A Layout Algorithm for Data Flow Diagrams*, IEEE TSE.** TSM 三段式框架的提出。
- **Fößmeier, Kaufmann 1996 — *Drawing High Degree Graphs with Low Bend Numbers*, GD 1995.** Kandinsky 模型（度 >4）。
- **Bläsius, Krug, Rutter, Wagner 2012/2014 — *Orthogonal Graph Drawing with Flexibility Constraints* / Kandinsky 复杂度.**
  证明 Kandinsky 最小弯折 NP 难；给出 flexibility 模型的多项式子类。
- ★ **Bridgeman, Fanto, Garg, Tamassia, Vismara 1997 — *Turn-Regularity and Optimal Area Compaction of Orthogonal Representations*, GD 1997.**
  紧致化的正确判据（kitty corner）。**这篇解释了"为什么紧致化会算错导致重叠"。**
- **Klau, Mutzel 1999 — *Optimal Compaction of Orthogonal Grid Drawings*, IPCO.** 流模型的面积最优紧致化。
- **Hopcroft, Tarjan 1974 — *Efficient Planarity Testing*.** 线性平面性测试。
- **Boyer, Myrvold 2004 — *On the Cutting Edge: Simplified O(n) Planarity by Edge Addition*, JGAA.** 现代实现首选。
- **Di Battista, Tamassia 1996 — *On-line Planarity Testing* / SPQR-tree.** 所有平面嵌入的表示。
- ★ **Gutwenger, Mutzel, Weiskircher 2001 — *Inserting an Edge into a Planar Graph*, SODA.** 可变嵌入的最优单边插入。
- **Chimani, Gutwenger, Mutzel 2007+ — OGDF 的 planarization 系列.** remove-reinsert 的工程化。
- **Papakostas, Tollis 1998 — *Algorithms for Area-Efficient Orthogonal Drawings*.** 面积界。
- **Purchase 1997/2002 — 见 §6。** 弯折 vs 交叉的实证权衡。

## 3. 边路由

- ★ **Wybrow, Marriott, Stuckey 2009/2010 — *Orthogonal Connector Routing*, GD 2009 / 期刊版.**
  libavoid 的核心：正交可见图构造、含方向状态的 A*、nudging 的偏序约束与环检测。**做正交路由必读。**
- ★ **Wybrow, Marriott, Stuckey 2006 — *Incremental Connector Routing*, GD 2005.** 增量重路由（交互场景）。
- **Miriyala, Hornick, Tamassia 1993 — *An Incremental Approach to Aesthetic Graph Layout*.** channel routing 的早期方案。
- **Yoshimura, Kuh 1982 — *Efficient Algorithms for Channel Routing*, IEEE TCAD.**
  VLSI 通道布线的 left-edge algorithm = 区间图着色。**03 篇 track 分配的原始出处。**
- **Lee 1961 — *An Algorithm for Path Connections and Its Applications*.** 迷宫路由（BFS）的祖宗。
- **Hart, Nilsson, Raphael 1968 — A* 原文。**
- **Holten 2006 — *Hierarchical Edge Bundles*, IEEE TVCG.** 层次边捆绑，性价比极高。
- **Holten, van Wijk 2009 — *Force-Directed Edge Bundling for Graph Visualization*, EuroVis.** 无层次时的捆绑。
- **Pupyrev, Nachmanson, Bereg, Holroyd 2011 — *Edge Routing with Ordered Bundles*, GD 2011.** 有序捆绑（MSAGL 的做法）。
- **Dwyer, Nachmanson 2009 — *Fast Edge-Routing for Large Graphs*, GD 2009.** 用稀疏可见图 + Sparse Visibility Spanner 加速。

## 4. 力导向与 Stress

- **Eades 1984 — *A Heuristic for Graph Drawing*, Congressus Numerantium.** 弹簧模型原文。
- ★ **Fruchterman, Reingold 1991 — *Graph Drawing by Force-Directed Placement*, Software: Practice & Experience.**
  FR 算法 + 退火，最广泛实现。
- **Kamada, Kawai 1989 — *An Algorithm for Drawing General Undirected Graphs*, IPL.** 基于图论距离的能量模型。
- ★ **Gansner, Koren, North 2004 — *Graph Drawing by Stress Majorization*, GD 2004.**
  SMACOF 在图绘制中的应用，单调收敛保证。neato 的 `mode=major`。
- ★ **Brandes, Pich 2007 — *Eigensolver Methods for Progressive Multidimensional Scaling of Large Data*, GD 2006.**
  PivotMDS：$O(kE)$ 得到高质量初始布局。**大图必备。**
- ★ **Ortmann, Klimenta, Brandes 2016 — *A Sparse Stress Model*, GD 2016.** $O(kV)$ 的 stress 近似。
- ★ **Zheng, Pawar, Goodman 2018 — *Graph Drawing by Stochastic Gradient Descent*, IEEE TVCG.**
  SGD stress：20 行代码、比 SMACOF 快且好。**推荐作为主力实现。**
- **Barnes, Hut 1986 — *A Hierarchical O(N log N) Force-Calculation Algorithm*, Nature.** 四/八叉树近似。
- **Hachul, Jünger 2004 — *Drawing Large Graphs with a Potential-Field-Based Multilevel Algorithm*（FMMM）, GD 2004.**
- ★ **Hu 2005 — *Efficient, High-Quality Force-Directed Graph Drawing*, Mathematica Journal（sfdp）.**
  多级 + BH + MIS filtration，工程细节丰富，易读。
- **Noack 2007 — *Energy Models for Graph Clustering*, JGAA.** LinLog：证明力模型最优解 ≈ 社区结构。理论亮点。
- **Jacomy et al. 2014 — *ForceAtlas2*, PLoS ONE.** 生产级力导向的参数与自适应步长设计。
- **Gansner, Hu, North 2013 — *A Maxent-Stress Model for Graph Layout*, IEEE TVCG.** 大图 stress 的近线性替代。
- ★ **Gansner, Hu 2009 — *Efficient Node Overlap Removal Using a Proximity Stress Model*（PRISM）, GD 2008.**
  消重叠的最佳质量方案（保 mental map）。
- **Freivalds, Dogrusoz, Kikusts 2002 — *Disconnected Graph Layout and the Polyomino Packing Approach*, GD 2001.** 分量装箱。

## 8. 度量与实证研究

- ★ **Purchase 1997 — *Which Aesthetic Has the Greatest Effect on Human Understanding?*, GD 1997.** 交叉 > 弯折 > 其它。
- **Purchase 2002 — *Metrics for Graph Drawing Aesthetics*, JVLC.** 可计算指标的定义（含对称性度量）。
- **Ware, Purchase, Colpoys, McGill 2002 — *Cognitive Measurements of Graph Aesthetics*, Information Visualization.**
  路径查找任务下"连续性/路径长度"比交叉更重要——对流程图有直接启示。
- ★ **Huang, Hong, Eades 2008 — *Effects of Crossing Angles*, PacificVis.** 交叉角度 ≥ 70° 几乎无害。**便宜的优化点。**
- **Di Battista, Garg, Liotta, Tamassia, Tassinari, Vargiu 1997 — *An Experimental Comparison of Four Graph Drawing Algorithms*, CGTA.**
  Rome 图集的来源与四种正交算法的量化对照。方法论值得学。
- **Dwyer et al. 2009 — *A Comparison of User-Generated and Automatic Graph Layouts*, IEEE TVCG.**
  人排 vs 机排：机器不输，但人更会用分组与对齐。
- **Klapaukh 2014 — *An Empirical Evaluation of Force-Directed Graph Layout*（PhD thesis, VUW）.** 力导向参数的系统实验。
- **Kieffer, Dwyer, Marriott, Wybrow 2013 — *Incremental Grid-Like Layout Using Soft and Hard Constraints*.** 网格化对齐的度量与实现。

## 9. 超图、总线与 VLSI 布线（对应 18 篇）

- **Mäkinen 1990 — *How to Draw a Hypergraph*, Int. J. Computer Math.** subset standard vs edge standard 的原初区分。
- ★ **Eschbach, Günther, Becker 2006 — *Orthogonal Hypergraph Drawing for Improved Visibility*, JGAA.**
  正交超边（总线形态）的完整建模与优化。**做总线必读。**
- **Sander 2004 — *Layout of Directed Hypergraphs with Orthogonal Hyperedges*, GD 2003.** 有向超图的分层绘制。
- ★ **Lengauer 1990 — *Combinatorial Algorithms for Integrated Circuit Layout*, Wiley.**
  VLSI 布局经典教材。分割、布置、全局/详细布线、通道布线——**图布局的很多"新"问题在这里已被解决四十年。**
- ★ **Yoshimura, Kuh 1982 — *Efficient Algorithms for Channel Routing*, IEEE TCAD.**
  left-edge algorithm（区间图着色）+ 垂直约束图。**分层图的层间路由 = 通道布线。**
- ★ **McMurchie, Ebeling 1995 — *PathFinder: A Negotiation-Based Performance-Driven Router for FPGAs*, FPGA'95.**
  **history cost + 拆线重布**——拥塞消解的正确机制，可直接移植到走廊拥塞。
- **Kernighan, Lin 1970 — *An Efficient Heuristic Procedure for Partitioning Graphs*, Bell System Tech. J.**
- **Fiduccia, Mattheyses 1982 — *A Linear-Time Heuristic for Improving Network Partitions*, DAC.** FM 的 gain bucket 结构值得学。
- **Karypis, Kumar 1998 — *METIS / hMETIS*（多级分割）.** 分组推断与大图 coarsening 的工业标准。
- **Ho, Sangiovanni-Vincentelli, et al. — Steiner 树在布线中的应用**；工程上只需 rectilinear Steiner 的近似（median trunk 即可）。
- **Pupyrev, Nachmanson, Bereg, Holroyd 2011 — *Edge Routing with Ordered Bundles*, GD 2011.**
  有序捆绑：比力导向 bundling 更适合工程图风格。

## 10. 一维排列、序列图与时间轴（对应 19 篇）

- ★ **Díaz, Petit, Serna 2002 — *A Survey of Graph Layout Problems*, ACM Computing Surveys 34(3).**
  MinLA / bandwidth / cutwidth / vertex separation 的统一综述。**次轴排列的理论底层。**
- **Garey, Johnson, Stockmeyer 1976 — *Some Simplified NP-Complete Graph Problems*.** MinLA NP 难的出处。
- ★ **Juvan, Mohar 1992 — *Optimal Linear Labelings and Eigenvalues of Graphs*, Discrete Applied Math.**
  Fiedler 向量作为 MinLA 的 $L_2$ 松弛最优解。谱方法做排序的依据。
- **Safro, Ron, Brandt 2006 — *Multilevel Algorithms for Linear Ordering Problems*, ACM JEA.** 千级以上的 MinLA。
- **Harper 1964 — *Optimal Assignments of Numbers to Vertices*.** 带宽下界的经典结果。
- **ITU-T Z.120 — *Message Sequence Chart (MSC)*.** 序列图语义的正式规范（比 UML 更严谨）。
- **OMG UML 2.5.1 §17 — *Interactions*.** 组合片段（alt/loop/par）的完整语义与图形约定。
- **Gregg 2016 — *The Flame Graph*, CACM.** 区间嵌套可视化的极简形态；验证抽象是否解耦。
- **Nagamochi, Kuroya 2007 — *Convex Drawing for c-Planar Biconnected Clustered Graphs*.** 排列与聚类的交互。

## 12. 计算几何、数值与零件（对应 14 / 15 篇）

  最小费用流 / network simplex 的权威参考（dot 的 rank.c 就是它的应用）。

## 13. 开源实现（读代码比读论文快）

| 项目 | 语言 | 读它学什么 |
|---|---|---|
| **Graphviz**（`lib/dotgen`） | C | dot 的分层全流程；`rank.c`（network simplex）、`mincross.c`、`position.c` 是教科书级 |
| **Graphviz**（`lib/neatogen`） | C | stress majorization、sfdp 多级、PRISM 消重叠 |
| **Eclipse ELK**（`elk.alg.layered`） | Java | **当代最完整的分层实现**：processor 依赖体系、端口约束、分组、from-sketch。强烈推荐通读其 processor 列表 |
| **OGDF** | C++ | 平面化、TSM、FMMM、SPQR-tree；学术算法最全 |
| **adaptagrams**（libavoid / libcola / libvpsc） | C++ | 正交路由、VPSC、IPSEP-COLA 的参考实现 |
| **WebCola** | TS | IPSEP-COLA 的可读实现 |
| **d3-force / d3-hierarchy** | JS | FR 简化版；Buchheim 树、treemap、pack 的干净实现 |
| **cytoscape.js + cose-bilkent** | JS | 复合图力导向（CoSE） |
| **MSAGL**（Microsoft Automatic Graph Layout） | C# | 分层 + 有序捆绑路由；Nachmanson 的工作 |
| **dagre** | JS | Gansner 1993 的简洁移植，代码量小，适合快速理解 |
| **mermaid / plantuml** | JS/Java | 产品级 DSL→图的完整链路（可对照本项目定位） |

**阅读建议**：先读 `dagre`（小、全）→ 再读 `Graphviz dotgen`（经典、细）→ 再读 `ELK layered`（最全、工程化）。
正交路由直接读 `libavoid`。VPSC 读 `libvpsc`（只几百行）。

## 14. 行业规范（做行业图种时的"需求文档"）

- **BPMN 2.0 规范**（OMG）：含 BPMN DI（Diagram Interchange）—— 定义了图形约定与坐标交换格式。
- **UML 2.x 规范**（OMG）+ **UML Diagram Interchange**。
- **SBGN 规范**（Process Description / Entity Relationship / Activity Flow 三册）：**图形约定最严格的范例**，读它能理解"产品化到极致"是什么样。
- **ArchiMate 规范**（The Open Group）：企业架构图的元模型与视觉约定。
- **ISA-5.1**（P&ID 仪表符号）、**IEC 60617**（电气符号）。
- **C4 Model**（Simon Brown）：软件架构图的分层叙事约定，对架构图种的信息组织很有参考价值。
