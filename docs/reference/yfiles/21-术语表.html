① 总纲 · 领域与架构

先建立"布局 ≠ 路由"这条最重要的架构分界线，再理解美学准则的实证排序。

Layout vs Edge Router 布局算法 vs 边路由器

架构分界

布局定节点坐标，路由定边路径 —— 两者是独立的一等公民。

为什么重要：把两者拆开，"分层布局 × 正交路由"这类组合免费获得。 这是 yFiles/现代引擎的关键决策，也是 plotgram 写权纪律的物理基础。

Aesthetic criteria 美学准则

软目标

"好看"是可量化的；准则 ≠ 玄学，但与"绘制约定"（硬约束）严格区分。

踩坑：把约定（"必须正交"）和准则（"少弯折"）混为一谈会让算法设计失焦。 优化时按此排序投入产出比最高。

② 分层布局 · Sugiyama 框架

流程图/架构图的主力算法。五相流水线 P1–P5，每相只写一个自由度。

Sugiyama 5-phase pipeline 五相流水线 P1–P5

P1 去环 P2 分层 P3 定序 P4 坐标 P5 画边

去环 → 分层 → 定序 → 坐标 → 画边。每相有且只有一个自由度的写权。

本项目最重要的纪律：每相只写一个自由度（P1 写 reversed 位、P2 写层号、P3 写层内序、P4 写次轴坐标、P5 写边路径）。 下游不得推翻上游，只得展开上游。修法若是"再加一个特判"，先问"这个自由度的写者应该是谁"。

Layer + Dummy node 层 + 虚节点

P2 / P3

长边穿过中间层时插入占位节点，使每条边都变成"相邻层"问题。

真实规模是 V + D，D 常是 V 的数倍。dummy 是"上游给下游留的展开点"，是写权纪律的物理体现。

Crossing minimization 交叉最小化

P3 定序

固定一层、优化下一层的顺序，来回多轮 sweep。两层版本已 NP 难。

Median 优于 barycenter：目标是 $L_1$ 型（位置差绝对值之和），而中位数是 $L_1$ 的最优点，有 3-近似保证。 必做：每轮记 best snapshot，结束时恢复 —— 最后一轮不一定最优，这条被反复忘记。

Edge weight 1 / 2 / 8 dot 经典配方

P3

real–real=1、real–dummy=2、dummy–dummy=8。让长边优先变直。

投入产出比最高的单项：几十行代码换来观感质变。BK 坐标分配下长边直线率应 >90%。

Brandes–Köpf (BK) 线性坐标分配

P4 坐标

线性时间坐标分配：4 次对齐 + 紧致化 + 取中位平均。工业默认。

必读 2020 勘误 —— 原文 compaction 伪代码有错，多个开源库因此出过节点重叠。 Type-1 conflict（真实边与长边交叉）必须标记，否则长边会被拉弯。

③ 正交布局 · TSM 三段式

"先定拓扑、再定形状、最后定尺寸"—— 极其干净的写权分层。

Orthogonal + Bend 正交 + 弯折

绘制约定

边只由水平/垂直段组成；bend 是 90° 拐点。是工程/电路/ER 图"专业感"的主要来源。

统计前必须先做共线合并，否则数字虚高。Bend 数是 P5/路由质量的第一指标。

TSM (Topology–Shape–Metrics) 拓扑–形状–度量

三段式

平面化（定拓扑）→ 正交化（定弯折形状）→ 紧致化（定实际长度）。

"先定拓扑、再定形状、最后定尺寸"是极其干净的写权分层，值得借鉴到任何布局。 Tamassia 流模型在固定嵌入下多项式时间最优 —— 正交布局的理论基石。

④ 边路由 · 产品观感的最后一公里

独立于布局的一等公民。核心难点：平行边不重合、A* 状态含方向、拥塞消解。

Nudging 微调 / 挪让

P5 / Router

把同走廊内的多条平行段横向错开，使其不重合且整齐。英文原词无标准中译。

和 VCG 环冲突是同一个问题：偏序有环时必须允许一次交叉（dogleg），不能"加特判"硬塞。

Track / Channel 通道 / 车道

VLSI 同构

Channel = 节点间的可通行空隙；Track = channel 内的一条车道。多条边并行各占一个 track。

分层图的层间空隙就是 channel —— 于是层间路由 = VLSI 通道布线，四十年成熟算法可直接搬。

Dogleg 折腿

破环机制

允许一条边中途换 track（加一段垂直跳转）。用于打破"垂直约束图"的环。

VCG 有环 = 互相要求在对方之上 = nudging 的环冲突。这是同一个问题在两个领域的化身，dogleg 是统一解法。

A* with direction state A* 状态含方向

最常见路由 bug

A* 搜索中状态必须包含进入方向 (vertex, dir)，否则弯折惩罚失效。

这是最常见的路由 bug。不记方向时，从东进和从北进到同一节点被视为同一状态，bend penalty 永远算 0。

⑤ 力导向 · Stress 框架

"力"是过时抽象；stress 是明确目标函数，因此可度量、可比较、可证明单调下降。

Stress function 应力函数

力导向

让画面距离逼近图论距离的加权平方和。

SGD stress（Zheng 2018）推荐作为主力实现：20 行代码、比 SMACOF 快且好，且不需要线性代数库。

⑥ 约束与稳定性

VPSC 是布局界的万能扳手；mental map 是交互的核心。

VPSC 分隔约束下的变量放置

万能扳手

求"各变量尽量靠近期望位置"且"两两满足最小间距"的二次规划，全局最优。

投入产出比排名前三。算法核心是 block 的 merge 与 split（按负 Lagrange 乘子）； 漏了 split 会在冗余约束下给出次优解。

Mental map 心智地图

交互稳定性

图变化时保持用户的空间记忆。三条可度量性质：正交序、邻近性、拓扑。

From-sketch / Incremental layout 是效果最好的单一稳定性手段（约 100 行）： 用当前坐标反推层与层内序作为初值。用户手工调过的元素应打 pinned。

⑦ 分组、泳道与端口

分组是产品级差异点；端口五档约束覆盖流程图 → ER → EDA 全谱。

Compound graph + Swimlane 复合图 + 泳道

分组

带嵌套容器的图。Swimlane = 按角色划分的横/纵带；PartitionGrid 统一实现泳道 + 阶段。

连续块约束（同组节点层内必须相邻）与"泳道内节点必须在同一列区间"是同一机制 —— 应共用实现。

Port constraint 五档 端口约束强度

递增约束

端口接到节点的具体位置；约束强度五档递增。

覆盖从流程图到 ER 字段级到 EDA 引脚的全部需求。 反模式：路由阶段临时发明端口是不可修复的 —— 默认策略应是"按对侧锚点坐标排序后均匀分布"。

⑧ 工程纪律 · 写权与 Stage

plotgram 的核心纪律：每个几何自由度有且只有一个写者。

Degree of Freedom / Write authority 自由度 / 写权

本项目红线

用 LayerWriter / OrderWriter / CoordWriter / RouteWriter 在类型层面约束谁能写什么。

让写权纪律从"文档约定"变成"编译器强制"。落笔相（Ink）零新决策：只展开上游已定的自由度，不发明端口、不挪节点。

Stage (decorator) 阶段装饰器

架构模式

包在核心算法外的"前处理 + 调用 core + 后还原"结构。

装饰器形式保证"还原"不会被忘记（平铺管线容易漏）。 典型：RemoveSelfLoops、HandleParallelEdges、ComponentLayout、TreeReduction、OrientationStage、Labeling、FixNode、NormalizeCoordinates。

⑨ 易混淆词对 · 读论文时的坑

大多数"算法缺陷"其实是概念混淆。下面 6 对最常见。

Crossing vs Overlap 交叉 vs 重叠

交叉 = 线与线相交（软指标）；重叠 = 面与面相交（硬断言，非 0 即 FAIL）。

Position vs Coordinate 层内序 vs 像素

分层布局中 position = 层内第几个（整数序），coordinate = 实际像素坐标。混用会写出错误代码。

Constraint vs Penalty 硬约束 vs 软惩罚

硬约束（VPSC/投影）vs 软惩罚（目标函数）。混淆会导致"约束有时不生效"。

Bend vs Waypoint vs Control point 弯折/途经/控制点

bend（几何拐点，在路径上）/ waypoint（强制途经点，约束输入）/ control point（贝塞尔控制点，可不在曲线上）。

Channel vs Track 通道 vs 车道

通道是空间（可容纳多条边）；track 是通道内的一条车道。层级关系，不要混用。

Determinism vs Stability 确定性 vs 稳定性

确定性 = 同输入同输出；稳定性 = 相似输入相似输出。 本项目红线：不得依赖 HashMap key 序。
