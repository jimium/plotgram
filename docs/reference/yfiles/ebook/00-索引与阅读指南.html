00 · 索引与阅读指南

yFiles 参考文库的入口：定位、文档清单、推荐阅读路径、写作约定

总览 本文库为 plotgram 自研布局 / 路由算法沉淀的算法级公开知识库
▸文库目的

为 plotgram 自研布局 / 路由算法沉淀一套算法级的公开知识库。内容来源：图绘制（Graph Drawing）领域公开论文、教科书（di Battista et al. Graph Drawing、Kaufmann & Wagner Drawing Graphs）、Graphviz / OGDF / ELK / adaptagrams 等开源实现的公开文档，以及 yFiles 公开文档与白皮书中可见的产品行为。不含任何 yFiles 私有源码信息——涉及 yFiles 的部分均为对其公开 API 语义与可观测行为的逆向归纳。

2推荐阅读路径

不同目标的读者，按下面顺序读最省力。

入门
第一次进这个领域：先建词汇表再读算法，能省掉大量"这词是啥"的往返。21 术语表 → 01 分层 → 03 路由
开工
直接开工：先看选型与架构，再补零件库。13 选型表 + 路线图 → 09 架构 → 14 工具箱
Hier 主路径
做 Hier（架构图 / 流程图主路径）：Sugiyama 是骨架；正交路由决定成品观感；分组/泳道/端口是产品级差异点。01 → 03 → 08 → 09 → 11
正交紧凑
做正交紧凑布局（ER 图、电路类）：02 → 03 → 06 → 18
Organic
做 organic / 知识图谱：04 → 07 → 11
序列图
做序列图 / 时间轴：19 → 06 → 08
架构
定引擎架构：09 + 20 必读，配合仓库内 写权纪律。
性能
优化性能：先度量再优化。16 → 11

4写作约定

  • 伪代码用 Rust 风格命名，但不承诺可编译；目的是表达数据流与写权。
  • 每个算法标注：出处（作者+年份）、复杂度、决定性（是否依赖迭代随机性）、写的自由度。
  • 「工程坑」小节记录开源实现（Graphviz/OGDF/ELK/libavoid）踩过的公开已知问题。
  • 汉语行文，算法术语保留英文原词（layering、crossing minimization、nudging…）以便检索论文。
