关于本 ebook

本 ebook 是 yFiles 参考文库 的 HTML 图文版，为 plotgram 自研布局 / 路由算法沉淀。内容来源：图绘制（Graph Drawing）领域公开论文、教科书 （di Battista et al. Graph Drawing、Kaufmann & Wagner Drawing Graphs）、Graphviz / OGDF / ELK / adaptagrams 等开源实现的公开文档，以及 yFiles 公开文档与白皮书中可见的产品行为。 不含任何 yFiles 私有源码信息——涉及 yFiles 的部分均为对其公开 API 语义与可观测行为的逆向归纳。
