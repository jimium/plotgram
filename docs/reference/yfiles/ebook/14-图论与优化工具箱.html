1最小费用流（Min-Cost Flow）——布局里最重要的优化零件

三处核心用途完全同构，值得实现一份通用求解器：

用途节点弧目标
P2 分层（dot）图节点边（下界 = minlen，费用 = 边权）最小加权总跨度
Tamassia 正交化顶点 + 面顶点↔面、面↔面最小弯折数
一维紧致化段相邻约束最小总长度

1.1 问题形式（本项目只需这一种）

带下界的最小费用可行流 / 或其对偶——最小加权跨度：

这是对偶于最小费用流的问题，也正是 VPSC 的整数/线性版本。注意：

  • 目标线性 → 用 network simplex（整数最优）；
  • 目标二次（最小化偏离期望位置的平方）→ 用 VPSC（07 篇）。

两者不要混用求解器。

1.2 Network Simplex（dot 的分层实现）

pseudo 
1. feasible_tree():
     init_rank()                      // longest-path 初值
     while tight_tree() 未覆盖全图:
         e = 非树边中 slack 最小者（一端在树内）
         delta = slack(e) * (方向符号)
         对树内所有节点 rank += delta   // 把 e 拉紧
     init_cutvalues()
2. loop:
     e = 树边中 cut_value < 0 的一条    // 有则说明可改进
     if 无: break
     f = enter_edge(e)                 // 在 e 的两个分量间找 slack 最小的非树边
     exchange(e, f)                    // 换基 + 增量更新 cut values
3. normalize(); balance()              // 顶端对齐 / 同 slack 节点居中
⚠关键实现细节（写错必踩）
  1. cut value 的定义：把树边 去掉后树分成两块 ； 。 说明把 head 侧整体移动可以减少总代价。
  2. 增量维护：叶子向内递推——一个节点只有一条未算的邻接树边时可 得出。 工程建议：先实现全量重算版本（）跑通，做完正确性测试再上增量。
  3. lim / low 区间：对树做 DFS 后序编号，low[v]..lim[v] 表示子树区间； 判断"某节点在 的哪一侧"变成 的区间包含测试。enter_edge 靠它剪枝。
  4. 迭代上限：dot 有 nslimit / nslimit1，超限就用当前可行解。必须有上限，否则病态图会卡死。
  5. 确定性：所有"选 slack 最小者"都要有稳定 tie-break（用边 id）。

复杂度：理论无强多项式界，实践近线性。dot 在数万节点上仍可用。

1.3 SSP（连续最短路增广）用于 Tamassia

Tamassia 的流网络规模小（面数 = ），用 SSP + Johnson 势（避免负边）即可：

pseudo 
while 存在供给未清:
    用 Dijkstra(带势) 在残量网络上求最短费用路
    沿路增广 min(残量, 剩余供给)
    更新势

复杂度 ， = 总供给（ 级）。

建模备忘（02 篇的流网络）：

  • 每个顶点 提供 单位流（度 ≤4 时非负）；
  • 每个面 需求 （内面）/ （外面）；
  • 顶点→其入射面的弧容量 1、费用 0（表示该角是 90° 还是 180°）；
  • 相邻面之间双向弧容量 ∞、费用 1（每单位流 = 一个弯折）。
  • 求得的流量 = 每条边上的弯折序列。

2匹配与流的其它用法

2.1 二分最大匹配（Hopcroft–Karp，）

  • 标签放置：候选位置 ↔ 标签，冲突图上求"每个标签选一个无冲突位置" → 匹配/独立集近似（06 篇）。
  • 端口分配：边 ↔ 固定端口槽位，最小化交叉的代价 → 变成指派问题（见下）。
  • 平面化：某些启发式用匹配挑选要删的边。

2.2 指派问题（Hungarian / KM，）

端口槽位分配的精确解：代价 = 该边接到该槽位产生的交叉/长度代价。 = 单侧端口数，通常 < 20， 完全可接受。 但：多数情况下"按对侧锚点坐标排序"就是最优解（因为代价矩阵满足 Monge 条件 → 保序最优），所以先用排序，只在有 FIXED_ORDER 混合约束时上 KM。

2.3 最小割 / 最大流

  • 图分割（用于泳道自动推断、社区分组的初值）；
  • k-way 分割建议用 METIS 风格的多级方法而非纯最大流。

3分解类算法

3.1 连通分量 / 强连通分量

  • 连通分量：BFS/DFS 或 Union-Find。用于分量分别布局 + 装箱（09 篇 ComponentLayout stage）。
  • SCC（Tarjan，）：
    • 去环前先求 SCC：只有 SCC 内部才需要反向边，跨 SCC 的边天然无环。这能把 Greedy-FAS 的工作量限制在各 SCC 内，且质量更好。
    • 缩点后得到 DAG → 可先在 DAG 上分层，再展开 SCC。

3.2 双连通分量与块割树（BCC / block-cut tree，Tarjan ）

  • circular 布局：每个 BCC 画成一个圆，块割树上做树布局（Six–Tollis）。
  • 平面化：平面性可按 BCC 独立判定。
  • 实现要点：用边栈而非节点栈；割点会属于多个块。

3.3 SPQR-tree（三连通分量分解）

表示图的所有平面嵌入：

  • S 节点 = 串联（环），R = 刚性（唯一嵌入，可翻转），P = 并联（可任意排列并联边），Q = 单边。
  • 用途：可变嵌入的最优边插入（Gutwenger–Mutzel–Weiskircher）——枚举 P/R 节点的选择做动态规划，在所有嵌入中找最短插入路径。
  • 复杂度：构造 （Hopcroft–Tarjan / Gutwenger–Mutzel 2000）。
  • 实现难度是本篇最高的。建议：先用固定嵌入（Boyer–Myrvold 给出的一个嵌入）+ remove-reinsert，只有在正交图种成为重点时才上 SPQR。

3.4 平面性测试与嵌入

首选 Boyer–Myrvold 2004（edge addition，）：

  • 同时给出嵌入（旋转系统）或 Kuratowski 子图（不平面的证据）；
  • 比 LR-planarity / PQ-tree 更易实现，且直接给嵌入。

次选 Left-Right planarity（de Fraysseix–Rosenstiehl，实现最短，约 200 行）。

4几何算法零件

4.1 扫描线（Bentley–Ottmann 家族）

三个变体，共用一套事件队列 + 状态结构：

任务状态结构复杂度
线段交点枚举按 y 排序的活动线段（平衡树）
矩形重叠检测区间树 / 有序集合
OVG 可见性构造活动区间集合

实现要点：

  • 事件按 (x, type, id) 排序，id 保证确定性；
  • 退化情形（共线、重合端点、垂直段）是 bug 温床 → 用整数/定点坐标或统一 epsilon 比较器；
  • 只需"是否存在交点"时用早退版本，快得多。

4.2 区间图着色（= 通道分配 / track 分配）

问题：给一组区间染色，重叠区间不同色，最小化颜色数。 贪心按左端点排序 + 最小可用颜色 = 最优（区间图是完美图，团数 = 色数）。

rust 
segs.sort_by_key(|s| (s.lo, s.id));           // 稳定
let mut free: BinaryHeap<Reverse<(Ord, Track)>> = ...;  // 按释放位置
for s in &mut segs {
    match free.peek() {
        Some(&Reverse((end, t))) if end + gap <= s.lo => { free.pop(); s.track = t; }
        _ => s.track = new_track(),
    }
    free.push(Reverse((s.hi, s.track)));
}

出处：Yoshimura–Kuh 1982 的 left-edge algorithm（VLSI 通道布线）。 用于：03 篇的层间 track、08 篇的泳道通道、06 篇的标签行分配。

⚠只有"区间"才最优

一旦加上"某些段必须在某些段之上"的偏序约束，就变成图着色（NP 难）→ 改用 nudging 的约束图 + 拓扑排序。不要把 left-edge 套到带偏序的场景，会得到错解。

4.3 累加树（Fenwick / BIT）与交叉计数

Barth–Jünger–Mutzel 双层交叉计数：

pseudo 
固定上层序，把每条边记为下层位置 p
按 (上层位置, 下层位置) 遍历边:
    crossings += query(p+1 .. maxIndex)   // 已插入且下层位置更大者
    insert(p)

。这是 P3 sweep 的内循环，必须高效。 同类技巧：用同一棵树可以增量算"交换相邻两点后交叉数变化"（transpose 的 判定）。

4.4 空间索引

  • R-tree（bulk-load 用 STR 打包）：适合静态查询多、更新少；
  • 均匀网格哈希：实现 30 行，在节点尺寸差异不大时比 R-tree 更快；
  • 四叉树：Barnes–Hut 复用（04 篇）。

建议：先做网格哈希；只有在节点尺寸跨 2 个数量级时才换 R-tree。

4.5 凸包与多边形

  • 凸包（Andrew monotone chain，）：组框的紧凑轮廓、分量装箱的形状近似；
  • 多边形布尔运算（用于组框合并）：建议避免——用轴对齐矩形 + 圆角就够，引入通用布尔库（clipper 类）会带来数值和体积成本。

5谱与线性代数零件

5.1 Fiedler 向量（第二小拉普拉斯特征向量）

用途：

  • circular 布局的节点排序（把相连节点排近）；
  • 谱分割（组自动推断）；
  • 一维排列的松弛解（19 篇 MinLA 的下界与初值）。

计算：不要求解完整特征分解。用 power iteration on deflated operator 或 Lanczos：

pseudo 
去掉全 1 方向：v ← v - (1ᵀv/n)·1
迭代 v ← (I - L/λ_max) v，归一化

。ARPACK 级精度不必要——排序只需相对大小。

5.2 PivotMDS 的 Householder 技巧

见 04 篇。要点： 个 pivot 的距离矩阵 （），双中心化后取 的前 2 个特征向量。。

5.3 共轭梯度 / Cholesky

SMACOF 每步要解 。 是稀疏对称半正定：

  • 小图（<5k）：稀疏 Cholesky（一次分解多次回代，因为 在迭代中不变）；
  • 大图：CG + Jacobi 预条件，10–20 次迭代足够（内层不需精确）。

如果用 SGD stress（推荐），这一节可以跳过——这是选 SGD 的一大理由。

6组合优化的近似与启发式模式

三种反复出现的模式，值得抽象成公共写法：

6.1 "扫一遍 + 局部交换"（sweep + transpose）

用于 P3 定序、标签、端口。骨架：

pseudo 
best = current
for iter in 0..MAX:
    global_pass()          // barycenter/median：跳出局部最优
    local_improve()        // transpose/swap：贪心下降
    if cost < best_cost { best = snapshot() }
    if cost == 0 || 无改进连续 N 轮 { break }
restore(best)
⚠必须保留 best snapshot

global_pass 可能变差，最后一轮不一定最优。这条被反复忘记——多个开源库都因此把已经更好的中间解丢掉。每次迭代结束都比较并保存最优快照，最后 restore(best)。

6.2 多级（coarsen → solve → refine）

用于 organic 布局、图分割、大图路由。骨架：

pseudo 
levels = [G]
while |levels.last| > threshold:
    levels.push(coarsen(levels.last))     // matching / MIS / 聚类
solve(levels.last)                        // 小图上精确/多迭代
for level in levels.rev().skip(1):
    interpolate(coarse → fine)            // 位置继承 + 扰动
    refine(level)                         // 少量迭代

coarsen 的三种选择：heavy-edge matching（最常用）、MIS filtration（sfdp）、solar system（FMMM）。

6.3 投影法（交替满足约束）

用于 IPSEP-COLA、消重叠、受约束排序：

pseudo 
loop:
    x ← 无约束优化一步（stress 梯度 / majorization）
    x ← project(x)          // VPSC 或 PAV，保证约束满足
    until 收敛

关键：project 必须是"最近可行点"投影（欧氏投影），否则不保证收敛。这就是为什么要用 VPSC 而不是启发式挪位。
