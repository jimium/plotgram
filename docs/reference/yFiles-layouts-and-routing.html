Hier 内建路由档
三类算法，不要混用职责 Layout：放置节点并通常同时生成边路径。Edge routing stage：节点冻结，只算边。 Labeling：节点与边路径不动，只摆标签。独立 Router 可作为任意 Layout 的后处理（ILayoutStage）。

主布局算法 · 特色

十个主风格；卡片右上为签名，下方为路由能力摘要。

HierarchicalLayout

分层 / Sugiyama · 流程图、调用图、ER、泳道、生化通路
有向流、层序、最小化交叉
  • 节点分到 rank 层，多数边朝主方向
  • 层内序优化交叉；端口 / 边组 / 增量 / group 一等公民
  • plotgram Atlas 主路径最接近的产品族
Ortho·内建 Poly·内建 Straight·— Curve·内建

默认 orthogonal；bus 靠 edge grouping；递归边另有 policy

OrganicLayout

力导向 · 社交/企业网络、生物信息、网格、系统管理
自然散布、显簇与对称
  • 节点互斥、边如弹簧；布局紧凑、邻接贴近
  • 边默认等长直线；另有 InteractiveOrganicLayout
  • 适合无强方向的中大型无向图
Ortho·可后接 Poly·可后接 Straight·内建 Curve·可后接

内建直线；正交/曲线通常后接 EdgeRouter / OrganicEdgeRouter

TreeLayout

树 + 子树放置器 · 组织树、数据流、软件结构、行政管理
树结构专用、高度可定制子树风格
  • 多种 ISubtreePlacer：正交、分层、压缩等
  • 可控制边序、端口、子树朝向
  • 非树边需预处理或换其它布局
Ortho·内建 Poly·内建 Straight·内建 Curve·可后接

路由风格 largely 由 subtree placer 决定，非整图单一 descriptor

RadialTreeLayout

气球 / 径向树 · 层级浏览、相似规模子树、目录树
子树绕父节点呈星/气球
  • 子女落在父节点圆周；子树像气球
  • 强调根到叶的径向层次感
  • 边通常直线
Ortho·可后接 Poly·可后接 Straight·内建 Curve·可后接

内建直线；换风格需独立 EdgeRouter

OrthogonalLayout

正交构图 · UML、DB schema、VLSI、楼层规划、知识表示
边全正交、紧凑、少弯少交叉
  • 边仅为水平/垂直段交替
  • 无节点重叠；适合中小稀疏图
  • 与 Hierarchical 正交不同：不强调全局层流
Ortho·内建 Poly·— Straight·— Curve·—

路由风格即正交；定向边可配 monotonic 约束

CircularLayout

环 / 多环 · 社交网络、电信、WWW、电商拓扑
按连通分区成环，强调群组
  • 单环或多环（分区盘）
  • 可突出 group / tree 子结构
  • 常配合边捆绑降 clutter
Ortho·可后接 Poly·可后接 Straight·内建 Curve·有限

默认弦/直线；bundling 是常见风格扩展

RadialLayout

同心圆层 · 聚类、社交、生物信息、树状径向变体
节点落在绕中心的同心层上
  • 多种 layering 策略（含 dendrogram）
  • 中心–外围语义清晰
  • 与 RadialTree 不同：不要求严格树
Ortho·可后接 Poly·可后接 Straight·内建 Curve·可后接

内建径向直线为主

SeriesParallelLayout

串并联 · 电路、调用树、结构化流程图
单源单汇、边弯最少、突出主路径
  • 图须（或近似）串并联可分解
  • 强调 source→sink 主方向
  • 路径感强、弯点少
Ortho·内建 Poly·内建 Straight·有限 Curve·可后接

内建偏正交/折线，强调最少弯

RadialGroupLayout

仙人掌分组 · 深层嵌套 group、包图式浏览
组成员绕组边界递归排布
  • 每组直接成员贴组边界排布
  • 递归树感像 cactus
  • 专为 hierarchically grouped 图
Ortho·可后接 Poly·可后接 Straight·内建 Curve·可后接

节点放置是主角；边风格常后处理

CompactDiskLayout

紧致圆盘 · 集合展示、无强边语义的节点云
节点塞进圆盘、最大化紧凑
  • 优化圆盘内紧凑放置
  • 弱化边几何，强调占用面积
  • 适合一堆节点而非复杂拓扑
Ortho·可后接 Poly·可后接 Straight·内建 Curve·可后接

边非优化目标；需要路径时后接 Router

独立边路由器（节点冻结）

实现 ILayoutStage；可挂在任意 Layout 之后：先放节点，再换边几何。

EdgeRouter

主力独立路由器

orthogonal · octilinear · curved · bus

节点冻结；增量重路由；可模仿 Hier/Ortho 的 monotonic 约束

OrganicEdgeRouter

有机曲线

smooth curves around nodes

绕节点平滑曲线；避重叠、减交叉

ParallelEdgeRouter

多边错开

parallel multi-edges

同对端点多边均匀错开

SelfLoopRouter

自环

loops

自环尺寸与曲率可配

BundledEdgeRouter

边捆绑

edge bundles

共享束降低 clutter、强调主流

StraightLineEdgeRouter

直线复位

straight

最简：端点直连

如何选（产品视角）

有主方向 / 流程

优先 Hierarchical（正交默认）。结构化单源单汇可试 Series-Parallel。需要泳道 / group 时 Hier 原生支持最强。

无方向网络

Organic 看簇与对称；要正交外观则 Organic 放置 + EdgeRouter。Circular / Radial 强调环与中心外围。

严格树

TreeLayout（正交/折线 placer）或 RadialTreeLayout（气球）。非树边先剥离或改 Hier/Organic。

已有节点坐标

只用 EdgeRouter / OrganicEdgeRouter / Bundled… 增量 Scope 可只重路由新增边，保 mental map。

对 plotgram 的映射提示 轻量子集：Hier ≈ Atlas 三相（组合→度量→Ink）；Tree / Sequence / Circular 为其它内核； 独立正交 OVG 已删，Hier 正交真源是 Channel Ink。yFiles 的「Layout 内建多种 routing style + 可后接 Router」双模式，对应产品上的 profile：内建路由 vs 节点冻结后的独立路由——不必复刻全表， 但选算法时先问主方向与边几何自由度写者。
