# Tautcore 内容块 MD 子集规范

> 版本：0.1-draft  
> 状态：现行（随 [ADR-005](../design/adr/005-content-measure-params.md) accepted）  
> 真源范围：**内容块 MD 子集语法 + Content AST**  
> 定稿选择：单个换行 = 硬换行（空行分段）；白名单外一律降级为字面文本、**永不 parse error**；行内标记不嵌套、不跨行；有序列表编号照写不重编；无序 marker 归一为圆点  
> 关联：[dsl-spec.md](dsl-spec.md)（`content` 属性嵌入形态，待增补）、[style-sheet-spec.md](style-sheet-spec.md)（typography 字段）、ADR-005（度量 / MeasureParams / ContentLayout）

**本文档定义**：节点内容块所接受的 Markdown 瘦子集——行级 / 行内语法、降级规则，以及解析产物 **Content AST**（只结构，不含任何宽高 / 坐标）。

**本文档不定义**（各自真源）：

| 内容 | 真源 |
|------|------|
| `content` 属性在 DSL 中的写法（多行 string 形态、转义） | dsl-spec（待增补） |
| `font_size` / padding 等度量与视觉字段 | style-sheet-spec + ADR-005 |
| `ContentLayout`（行盒 / run 几何）、preferred size、wrap / 截断策略 | 度量相（ADR-005 §2） |
| ER 字段表 / 结构化框内模型 | 另案（ADR-005 明确出圈） |
| ASCII 后端 | 不适用：ASCII 只画 `label`，不消费内容块 |

## 1. 输入模型与归一化

输入是一段 UTF-8 文本（载体无关；DSL 如何携带见 dsl-spec）。解析前做且仅做以下归一化：

1. 换行统一为 `\n`（`\r\n` / `\r` → `\n`）
2. 每行**行尾**空白剥除（行首空白保留，供行分类使用）
3. 文首、文尾的空行剥除

解析是**纯函数**：同一输入必得同一 AST；实现内不得使用 `HashMap` 等无序容器（工程红线）。

规模不设 parse 硬上限；建议 lint 层告警阈值（如 > 64 行或 > 2048 字符），是否截断由度量相的 max 宽高策略决定，**不在本规范**。

## 2. 行级语法

归一化后逐行分类，**自上而下按序判定，命中即止**：

| # | 判定（对整行） | 行类型 |
|---|----------------|--------|
| 1 | 仅含空白或为空 | 空行（块分隔符） |
| 2 | 去除首尾空白后为 3 个及以上 `-`，无其它字符 | 分隔线 `Rule` |
| 3 | 以 `- `（连字符 + 一个空格）开头，**无行首缩进** | 无序列表项 |
| 4 | 以 `1–3 位数字 + "." + 空格` 开头，**无行首缩进** | 有序列表项 |
| 5 | 其它 | 段落行 |

要点：

- `---` 与列表不歧义：分隔线整行只有 `-`，列表项要求 `- ` 后必有内容位。
- **行首有缩进的行一律按段落行处理**（含缩进的 `- x` / `1. x`）。这就是「单层列表」的落地方式：嵌套写法不报错，降级为文字。
- 列表项内容为 marker 之后的剩余文本，做行内解析；**每项恰一行**，不支持跨行续行（lazy continuation 不做）。

### 2.1 块的聚合

- 连续段落行 → 一个 `Paragraph`；段内每一物理行是一个硬换行后的 `Line`（**单个换行 = 硬换行**；不采 CommonMark soft break，不做行尾双空格魔法）。
- 连续**同类**列表项行（同为无序或同为有序）→ 一个 `List`；类型切换即开新 `List`。
- 空行结束当前块；连续多个空行等价于一个。
- `Rule` 自成一块。

### 2.2 列表 marker

- 无序：仅认 `- `（不认 `*` / `+`，避免与行内 `*` 纠缠）；渲染时 marker 归一为固定圆点字形（字形选取属渲染 / 度量相）。
- 有序：`<digits>. `；**编号照作者所写**，解析存原数字，不重编号、不接续（`3.` 起头就画 `3.`）。

## 3. 行内语法

每个 `Line`（段落行或列表项内容）独立做一次**从左到右单遍扫描**，产出 styled run 序列。作用域是单行：任何行内标记**不跨硬换行**。

判定优先级（扫描到某字符时按此顺序）：

| # | 触发 | 语义 |
|---|------|------|
| 1 | `\` 后跟 `` ` `` `*` `\` | 转义：产出该字面字符；`\` 后跟其它字符 → `\` 与该字符均为字面量 |
| 2 | `` ` `` | code span：至同行下一个 `` ` `` 止，内部**全字面**（转义不生效、不再解析 `*`）；同行无闭合 → 该 `` ` `` 为字面量 |
| 3 | `**` | strong：至同行下一个 `**` 止；内容**非空且首尾非空白**则成立；内容按**纯文本**处理（转义生效，`` ` `` / `*` 不再开启新标记——**不嵌套**）；否则 → 字面量 |
| 4 | `*` | emph：规则同 strong（闭合符为 `*`）。首尾非空白约束使 `3 * 4 * 5` 保持字面 |
| 5 | 其它 | 字面文本 |

产物为 run 序列，每个 run 恰有一种样式：

```
RunStyle ::= plain | strong | emph | code
```

相邻同样式 run 合并；不产生空 run。**没有**组合样式（`**` 内的 `*` 是字面量），这保证 run 模型扁平、与 `ContentLayout` 的行盒 / run 几何一一对应，度量只需按 `RunStyle` 选估宽系数。

---

## 4. 降级原则

**解析永不失败。** 白名单（§2、§3）之外的一切 Markdown / 类 Markdown 写法——`#` 标题、`>` 引用、表格、图片、链接、HTML 标签、嵌套列表、多级强调——均无特殊语义，按字面文本落入段落 / 列表项。内容块写错的最坏结果是「文字长得不像预期」，不得影响解析、布局与出图。

因此本子集**没有 error 词表**；lint 告警（如疑似嵌套列表缩进）可选，非契约。

## 5. Content AST

只描述结构；**不含任何宽高、坐标、字号**（几何唯一写者是度量相，见 ADR-005 §2）。字段名以实现为准，结构为契约：

```
ContentDoc ::= Block*

Block ::= Paragraph { lines: Line+ }
        | List      { ordered: bool, items: ListItem+ }
        | Rule

ListItem ::= { number: u32?, line: Line }   // number 仅有序列表有，为作者原编号

Line ::= Run+
Run  ::= { text: String, style: RunStyle }
```

不变量：

- `Paragraph.lines`、`List.items`、`Line` 的 run 均非空
- 相邻同 `style` 的 run 已合并
- `ContentDoc` 可为空（空输入 → 零 block）
- 序列化 / 遍历顺序 = 源文本顺序（确定性）

消费方（见 ADR-005 §2 写权表）：

| 消费方 | 用途 |
|--------|------|
| 度量相 | AST + MeasureParams → `ContentLayout`（含 size） |
| render（SVG） | 按 `ContentLayout` 出 `<g>` 片段；**不**回读 AST 重排 |

## 6. 示例

源：

```
**订单服务**
---
处理下单主链路：
- 校验库存
- 落库并发 `order.created`
1. 幂等键去重
```

AST（示意）：

```
Paragraph [ Line [ Run(strong "订单服务") ] ]
Rule
Paragraph [ Line [ Run(plain "处理下单主链路：") ] ]
List(unordered) [
  { line: [ Run(plain "校验库存") ] },
  { line: [ Run(plain "落库并发 "), Run(code "order.created") ] },
]
List(ordered) [
  { number: 1, line: [ Run(plain "幂等键去重") ] },
]
```

降级示例：

| 源 | 结果 |
|----|------|
| `# 标题` | 段落行，字面 `# 标题` |
| `  - 嵌套项`（有缩进） | 段落行，字面 `- 嵌套项`（前导空白保留为字面） |
| `**没闭合` | 段落行，字面 `**没闭合` |
| `a * b * c` | 字面（emph 内容首尾为空白 → 不成立） |
| `\*不强调\*` | 段落行，字面 `*不强调*` |

## 7. 测试要求

依 AGENTS.md 单测约束：

- 表驱动：语法 / 降级 case 合并为一个 `#[test]` + 循环，断言 AST（`insta` snapshot 或结构相等）
- 闭环测试属于度量 / render 层（同 AST + 同 MeasureParams → 尺寸快照稳定），不在本规范重复
- 确定性属性保留最高层一次即可
