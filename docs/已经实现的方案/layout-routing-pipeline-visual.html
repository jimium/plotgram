1三层 Frame 模型

整个 pipeline 由三层 Frame 模型贯穿：L1 组间 → L2 组内 → L3 节点。L2 由布局算法内部完成，L3 在路由前做结构对齐，L1 组框在 L3 之后、路由前后多次幂等应用，边像素量化在管道最末尾执行一次。

5流程图布局 sugiyama_v2 + flowchart 分治

sugiyama_v2 是共享引擎（NS rank + 加权中位数 + BK 坐标），flowchart 在其上做 group_divide 分治。

sugiyama_v2 四阶段

阶段 0+1: 建图 + greedy_fas 去环
阶段 2: NS-style 紧边压缩（256 轮上限，5 轮无改进早停）
阶段 2.5: 语义/group rank 约束
阶段 3: 加权中位数 + 转置（16 轮上限）
阶段 4: BK 四趟坐标分配 + compact + 重叠消除
NS 主循环关键： longest_path → feasible_tight_tree → cut_value pivot → simplex_state_key 去重防振荡

flowchart 分治（group_divide.rs）

1. GroupTree::build + 识别顶层 group
2. 每个顶层 group 调 layout_intra（子图清空 group_id）
3. 无 group 节点作为 UNGROUPED 虚拟组
4. collect_cross_edges 收集跨组边
5. StackingArrangement.arrange → 各 group 偏移
6. 合并全局坐标 + 路由 hints
注意：分治路径不支持拓扑意图叠加（有 group 时忽略 overlay）

排序比较器 8 级 tiebreaker（order.rs:102）

1. median
主键，加权中位数
2. group 偏置
|diff|<1 同组相邻
3. barycenter
重心
4. degree
高度数优先
5. is_dummy
dummy 优先
6. spread
分布
7. layer_node_sort_key
Real 优先 + index
8. 原始位置

8Refine 精修与 spline 兜底

节点布局+边路由完成后，检测折线边穿过非端点节点的情形，局部推开问题节点并重新路由。

RefineConfig

enabled: true (默认)
max_passes: 3
push_distance: 40px
node_shrink: 2px (穿障检测内缩)
combined_crossing_score = edge_node_crossings × 10 + edge_overlaps

主流程 run_refine

1. analyze_crossings → 若 0 直接返回
2. 循环 max_passes: 收集 edges_to_reroute → push_problem_nodes → reroute_subset → 评估
3. 新 score < best → 接受；否则回退 break
4. P2-2 兜底：仍穿障的边 → spline_fallback 可见性图绕障
5. spline 无路径 → 退化为 Bezier

子模块

11Friendliness 友好性评估

在节点布局完成后、边路由前基于拓扑与位置快速预测布局对路由是否友好。分数越低越友好（0=完美，可为负）。

维度评估目标

V2 adjuster

配置：max_passes=5, push_distance=80px, momentum_damping=0.5, min_crossings=2
流程：compute_crossing_details → 若 < min 直接返回 → 迭代 push_crossed_nodes → 重叠守卫 → 接受/回退

12Intent 意图系统

布局算法之上的可选修正层，不变异 Diagram，保持 relations[i] ↔ edges[i] 索引契约。

两类意图

Below{from, to} → 注入 B→A
Above{from, to} → 注入 A→B
GeometricIntent：

AlignVertical{nodes}
AlignHorizontal{nodes}

校验与精修

validate_topology_intents：节点存在性 → 自环 → 矛盾去重 → 环检测（DFS has_path）
FAS 保护：真实边成环时 FAS 仅反转真实边，意图边 reversible=false 永不反转

check_alignment_after_refine：refine 后中心极差 > 1.0 → 降级为 Partial（不回滚）

14确定性保障（AGENTS.md §2）

所有迭代/排序点显式避免 HashMap key 顺序驱动，使用 BTreeMap / BTreeSet / 显式排序。

关键确定性点

  • NS 主循环：组件/节点/边按 index() 排序；simplex_state_key 去重防振荡
  • 排序阶段：8 级 tiebreaker 落到 layer_node_sort_key + 原始位置
  • BK 坐标：4 趟固定优先级 down_left > down_right > up_left > up_right
  • group_divide：GroupTree 按 ID 排序；topological_sort_groups 用声明顺序
  • FAS：sinks/sources 每轮 sort()；then_with(|| b.cmp(a)) 确定性 tiebreak
  • architecture_v2：邻接表 sort、rank_indices、super_edges_sorted、group_ids 均显式排序
  • replan_slots：AnchorBlock 块间 dir_key → center_tangent → min(edge_index) 全序
  • lane_assignment：BTreeMap 保证组遍历顺序确定
  • grid_snap：cluster_by_rank_axis 按 (center, id) 稳定排序
  • visibility shortest_path：Dijkstra 等距用 node 作稳定 tiebreak
  • group_frame：ranks 升序、块 id 升序；realign 按 group id 字典序

关键设计要点

  1. P1 量化延后：末尾执行一次
  2. NodeAlign / EdgeSnap 拆分：结构修正 vs 视觉优化独立
  3. 三层 Frame 模型：L2→L3→L1→friendliness+route+refine→L1 幂等→Edge Snap
  4. friendliness 解耦：off/diagnose/adjust 三档
  5. 增量重路由：route_after_node_moves 基于位移节点集
  6. Layout↔Route 反馈闭环
  7. Bundling 三档汇流（Single/Compact/Concentrate）
  8. Lane Assignment 车道分配（cross-axis 平移，保持正交）
  9. X-1 多轮冲突消解（递增 margin + 三重硬检查）
  10. 安全回退（走廊→通用→spline→Bezier）
