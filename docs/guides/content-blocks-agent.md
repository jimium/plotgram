# 内容块 MD 子集（Agent 速查）

> 真源：[content-md-spec.md](../specs/content-md-spec.md)；人类版：[content-blocks.md](content-blocks.md)

## 语法（白名单，仅此）

```
**加粗**  *斜体*  `代码`   ← 行内，不嵌套，不跨行；`内部全字面
\* \` \\                   ← 转义仅这三个
换行 = 硬换行；空行 = 分段
---                        ← 整行 ≥3 个 - = 分隔线
- 项                       ← 无序列表（只认 "- "，行首不可缩进）
1. 项                      ← 有序列表（编号照写不重编）
```

## 规则

- 白名单外一切（`#` 引用 链接 表格 嵌套列表 组合样式）**降级为字面文本，永不报错**
- 标记没闭合 / 内容空 / 首尾空白 → 字面（`3 * 4 * 5` 保持字面）
- 缩进的 `- x` / `1. x` → 普通文字（即：无嵌套列表）

## 不在文本里的东西

- **颜色 / 字号**：无行内语法。语义（strong/emph/code）→ 主题 `ContentPaint` 按样式配色
- **换行 / 对齐 / 截断**：`MeasureParams` 的 `max_width` / `align`(left|center|right) / `max_lines`（末行补 `…`），调用方参数

## 生成建议

- 典型结构：`**标题**` + `---` + 正文/列表
- 技术标识符（字段、topic、命令）用 `` ` `` 包裹
- 别写白名单外语法赌运气——只会得到字面文本
