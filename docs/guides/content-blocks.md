# 节点内容块：MD 子集用户手册

> 面向：写图的用户 / 接入内容块的开发者
> 实现：`crates/plotgram-content`（parse → measure → emit，ADR-005）
> 规范真源：[content-md-spec.md](../specs/content-md-spec.md)（语法契约以规范为准，本文是使用说明 + 示例）

节点除了单行 `label`，还可以携带一段**内容块**：一段瘦身版 Markdown 文本，渲染成节点内部的多行富文本（标题、分隔线、列表、代码片段等）。

设计基调是**克制**：语法白名单极小、写错永不报错（最坏就是按字面显示）、文本里只有语义没有视觉——颜色、字号全部由主题决定。

---

## 1. 三分钟速查

```
**订单服务**                ← 加粗（strong）
---                         ← 分隔线
处理下单主链路：            ← 普通段落行
- 校验库存                  ← 无序列表
- 落库并发 `order.created`  ← 行内代码（code）
1. 幂等键去重               ← 有序列表（编号照你写的画）
再来一行 *强调文字*         ← 强调（emph，斜体）
```

| 想要 | 写法 | 备注 |
|------|------|------|
| 加粗 | `**文字**` | 首尾不能是空白 |
| 强调（斜体） | `*文字*` | 同上；`3 * 4 * 5` 会保持字面 |
| 代码片段 | `` `文字` `` | 内部全字面，不再解析任何标记 |
| 换行 | 直接换行 | **单个换行就是硬换行**，没有行尾双空格魔法 |
| 分段 | 空行 | 段落之间有额外间距 |
| 分隔线 | 整行 `---`（≥3 个 `-`） | 常用来隔开标题与正文 |
| 无序列表 | `- 内容` | 只认 `- `，不认 `*` / `+`；圆点字形自动归一 |
| 有序列表 | `1. 内容` | 编号照写不重编：从 `3.` 开始就画 `3.` |
| 字面 `*` `` ` `` `\` | `\*` `` \` `` `\\` | 转义只对这三个字符生效 |

**没有的东西**（写了不报错，按字面显示）：`#` 标题、`>` 引用、链接、图片、表格、嵌套列表、加粗套斜体等组合样式。

## 2. 行级语法

### 段落与换行

- 每个换行都是**硬换行**：所见即所得，一行源文本 = 一个视觉行（除非触发自动换行，见 §4）。
- 空行分段，段落之间有 `paragraph_gap` 间距；连续多个空行等价一个。

```
支付超时 30s
重试 3 次后入死信队列 DLQ

*注意*：对账任务每日 02:00 执行
```

→ 两段：前两行是一段（两个视觉行），空行后另起一段。

### 列表

- 一项一行，不支持跨行续行；**行首不能有缩进**（有缩进的 `- x` 会被当成普通文字——这就是"不支持嵌套列表"的落地方式）。
- 无序与有序相邻会各自成组；有序编号存作者原文。

```
**发布流程**
1. 构建镜像 `docker build`
2. 推送 registry
3. 滚动更新 *无损*
```

### 分隔线

整行只有 `-`（3 个及以上）才是分隔线；`- ` 后面有内容就是列表项，两者不歧义。

---

## 3. 行内语法

单遍从左到右扫描，作用域是**单行**（任何标记不跨换行）。优先级：转义 > `` ` `` code > `**` strong > `*` emph。

要点：

- **不嵌套**：`**加粗里的 *星号* 是字面**`——strong 内部不再解析。
- code span 内部**全字面**：`` `a * b` `` 里的 `*` 不会变斜体，转义也不生效。
- 标记没闭合、内容为空、首尾是空白 → 不成立，按字面显示。

降级示例（这些都**不会报错**）：

| 源 | 显示结果 |
|----|----------|
| `# 不是标题` | 字面 `# 不是标题` |
| `  - 缩进不算列表` | 字面（含缩进） |
| `**没闭合` | 字面 `**没闭合` |
| `3 * 4 * 5` | 字面（emph 首尾是空白 → 不成立） |
| `\*字面星号\*` | `*字面星号*` |

## 4. 布局能力（调用方参数，不是文本语法）

以下能力由 `MeasureParams` 控制（DSL / style sheet 层传入），文本里不需要也不能写：

| 参数 | 效果 |
|------|------|
| `max_width` | 自动换行预算。CJK 逐字可断（带避头尾：`，。）` 不落行首、`（「` 不挂行尾）；拉丁词整词移动；超长 token 硬切。列表续行保持缩进，圆点只画在首行 |
| `align` | `left / center / right`：行在内容盒内的水平对齐（居中标题节点常用） |
| `max_lines` | 最多保留 N 个视觉行，末行自动补 `…` 并重新塞回预算内；固定尺寸节点防溢出 |

```text
max_width: 200, max_lines: 3 下的效果：

**变更公告**
---
本次升级包含账务核心迁移，涉         ← 自动换行
及订单、支付、结算三个域的…         ← 第 3 行截断 + 省略号
```

## 5. 颜色怎么控制

**文本里没有颜色语法**——你标语义，主题配颜色：

- 文本层只写 `**strong**` / `*emph*` / `` `code` ``；
- 主题层（`ContentPaint`）按样式统一配色：正文基色 `text_fill`，可选覆写 `strong_fill` / `emph_fill` / `code_fill`（`None` = 继承正文色），另有 `code_chip_fill` 给代码片段画底色 chip、`rule_stroke` 给分隔线上色。

好处：换主题（比如暗色）时内容文本一个字不改；同一张图里所有 code 的观感必然一致。不能把某个词单独涂红——将来若需要"这个节点是警告色"，入口是 DSL 节点属性的语义 tone，由 style sheet 展开，依然不会出现行内颜色语法。

## 6. 完整示例

```
**API Gateway**
---
责任：鉴权、限流、路由
- JWT 校验（RS256）
- 限流 *1000 QPS*
- 灰度路由 `x-canary`
```

渲染效果：加粗标题 → 分隔线 → 一行正文 → 三个圆点列表项，其中 `1000 QPS` 为强调色斜体、`x-canary` 为等宽字体 + 代码底色 chip。

更多样例（含换行、居中、截断、降级）可本地一键生成对照画廊：

```bash
python3 scripts/content_gallery.py    # 渲染 9 个典型样例 + 真字体对照，自动打开浏览器
```
