Group 不该靠「再灰一点」来存活

旧方案失败的根因不是色值没调准，而是策略同质：十个方案都在微调 L1 填充明度。 真正要解决的是 canvas → group → edge → node 的四元平衡： 分组要可读，连线也要可读——不能靠把 edge 调虚来「让出」group。 另有产品硬约束：嵌进 Cursor / Markdown 灰白底时，不能靠压暗 canvas 换层次。

当前失败诊断

  • L1 透明/纯白，边界几乎只靠 #9CA3AF 虚线
  • edge #BDBDBD 与 group stroke 抢同一灰阶 → 双方都糊
  • 若只调浅 edge「让位」给 group，关系信息反而先死
  • 正确拆法：group 用填充建体，edge 保持可追迹对比度
  • 语义节点独占饱和度；箭头青绿可保留为端点锚点
P1

先定关系，再定色值

每个方案先声明「谁更亮、谁更暗、谁管边界」，色值只是落地。

P2

Edge 是内容，不是配角

连线承载关系信息。禁止靠大幅调浅 / 降 opacity 换 group 清晰。edge 对最深 group 填充仍须可追迹。

P3

语义色独占饱和度

group 只允许近灰或极低饱和大气色；蓝/橙/绿留给节点。

P4

嵌套要可数

L1/L2/L3 至少有一种通道可辨：明度台阶、线宽、或 dash——不要靠猜。

P5

嵌入优先

默认 theme 的 canvas 须近白或透明，贴合宿主灰白底。层次放在 group，不放在画布。

P6

Group 用填充建体

分组身份优先靠 fill 台阶，而不是跟 edge 抢 stroke。stroke 只做轻微分工（线宽 / 实虚），别逼 edge 让路。

01

浮岛白卡 · Floating Cards

把 canvas 压暗，让 group 以白卡「浮」在纸面上。边界靠明度落差成立，不再依赖与 edge 抢灰阶。在独立全屏里很漂亮——但嵌入 Cursor / Markdown 灰白底时，整图会变成一块融不进去的灰盘子。已从默认推荐中撤下。

仅限全屏不适合默认嵌入
canvas #E2E2E6 L1 #FFFFFF L2 #F7F7F8 L3 #EFEFF1 node #FFF edge #A8A8B0 g-stroke #C4C4CB
nest = lighter → darker · solid stroke

机制

canvas 比 L1 暗约 8–10 L*，group 轮廓由「白岛落在灰纸」成立；edge 走在白/浅灰面上，与 stroke 不再同级竞争。

代价 · 嵌入

致命点：宿主已是灰白时，加深的 canvas 自身变成第二层「卡片底」。文档里会出现灰矩形嵌灰白页，比 group/edge 糊更扎眼。

落地

只适合 playground / 导出海报 / 自有深色 chrome 全屏。默认 clean-light 不要压暗 canvas。

02

凹井分层 · Recessed Wells

canvas 近白/透明贴宿主；group 比画布更深形成凹井；节点抬白。分组身份靠 fill 台阶成立——edge 不必让路，反而可在深底上保持清晰追迹。修订后的默认首选。

默认首选嵌入友好 · edge 可读
canvas #F7F7F8 L1 #ECECEF L2 #E2E2E6 L3 #D8D8DE node #FFF edge #9C9CA6 g-stroke #B0B0B8
nest = darker wells · white nodes

机制

嵌套越深越暗（well），节点抬升为白/语义色。group 靠 fill 建体；edge 用 #9C9CA6 压在井底上仍可追迹——这是「加深 edge 适配深底」，不是「调浅 edge 让位」。

代价

三层以上会偏闷；neutral 节点必须抬白，否则沉进井底。edge 不能再比现状更浅。

落地

canvas #F5F5F5/transparent；group_nest 递加深；node 抬白；edge 维持或略加深。箭头青绿保留为端点锚。

03

轮廓优先 · Contour First

想靠加深 group stroke、几乎不动 fill。风险：若同步把 edge 调浅到 #D4D4D8，关系线会先糊掉。只有在「edge 保持可读、仅靠线宽/虚实分工」时才成立——下方示意已按此修正。

有条件可用禁止饿死 edge
canvas #F5F5F5 L1 ≈ transparent L2 #F3F3F3 L3 #EBEBEB node #E4E4E4 edge #9A9AA3 可读 g-stroke #52525B
L1 1.75px dash · edge 保持对比 · 不降 opacity

机制

group 靠更深/更粗的轮廓；edge 保持 #9A9AA3 级对比。两者靠线宽与虚实分工，而不是明度对掐。

风险

fill 弱时，深轮廓仍可能被密线切断。且深线框易喧宾夺主。不如 02 稳。

否决项

任何把 edge 调到接近 #D4D4D8 或 opacity < 0.9 的变体，直接否决。

04

雾蓝大气 · Atmospheric Mist

给整张图一层「空气感」冷雾——不是品牌靛蓝，也不是语义蓝。色相只用来标记「这是空间」，饱和度压到几乎无彩。气质好，但冷雾 canvas 在纯白宿主上仍可能露出一圈淡蓝灰「色差边」。

气质佳嵌入有轻微色差
canvas #F0F2F5 L1 #E8ECF2 L2 #DEE4EC L3 #D4DCE6 node #FFF edge #9AA3B0 g-stroke #8B95A5
hue ≈ 214° · chroma < 0.02 · cool mist

机制

单一冷雾色相贯穿 canvas→L3，靠明度台阶嵌套。色相与暖橙/绿节点形成冷暖对比，却不会撞上 semantic blue 的饱和度。

代价 · 嵌入

相对纯白宿主，冷雾底会形成淡色差矩形。比 01 轻得多，但不如 02/06 隐形。

落地

若采用：优先把雾色只铺在 group，canvas 保持白/透明，可消掉宿主色差。

05

纸墨系统 · Paper & Ink

画布用暖纸，分组用极浅暖灰井，连线用冷墨灰。冷暖分工：纸管空间，墨管结构。语义色在暖纸上天然更醒目——这是「有性格但不花哨」的路线。

有性格偏离纯 clean
canvas #F3F0EA L1 #EAE6DF L2 #E1DBD2 L3 #D8D1C6 node #FFFEFA edge #8A8790 g-stroke #A39E94
warm paper · cool ink edges

机制

暖纸 + 冷墨是跨通道对比：即便 fill/stroke 明度接近，色温差仍能让人读出「边 vs 框」。

代价

与现有「cool / modern」标签略冲突；导出到纯白文档里可能显脏。

落地

适合作为独立 theme 变体（如 clean-paper），不宜直接覆盖 clean-light 默认。

06

双通道边界 · Dual-Channel Boundary（修订）

填充建体 + stroke 轻分工；edge 不降权。旧版「edge @0.85 / #C4C7CE」已否决——那是牺牲关系清晰度。修订后与 02 接近，差别只在 fill 台阶更浅、可分步上线。

可分步上线edge 保持可读
canvas #F5F5F5 L1 #ECEEF2 L2 #E4E6EB L3 #DBDEE4 node #FFF edge #8F8F99 g-stroke #7A7A86
fill 建体 · stroke 轻差 · edge 不加透明

机制

① L1+ 有可辨 fill ② group stroke 仅比 edge 略深/略粗 ③ edge 维持 #8F8F99、opacity=1。分组不靠饿死连线取胜。

与 02 关系

同属「fill 建体」家族；06 台阶更浅、更接近现状，适合分步验证。效果不够再加深到 02。

落地

先加 L1 fill → 再微调 stroke → 最后才动 edge，且只允许加深不允许调浅。

怎么选 · 嵌入 + edge 可读

默认 clean-light：优先 02（或温和版 06）。canvas 近白；group 用 fill；edge 保持可追迹。禁止「调浅 edge 让 group 赢」。
